hrefとsrcの違い｜どちらもURLっぽいけれど役割は違う

hrefは「参照先」、srcは「読み込み元」。どちらも場所を指定しますが、何のための場所なのかを、前にあるタグと一緒に読むと分かります。

まず結論：参照先と、読み込み元

HTMLを読んでいると、href="..."やsrc="..."が出てきます。こうしたタグに付く情報を「属性」と呼びますが、まずは次の感覚で読めれば十分です。

  • href：「どこを見る・どこへ行く？」という行き先・参照先。
  • src：「何をここへ持ってくる？」という読み込むものの場所。

ただし、「hrefなら読み込まない」という区別ではありません。CSSを参照する<link>でも、実際にはファイルが読み込まれます。タグを見て、その場所をどう使うのかを読むのがポイントです。

英語から覚える：referenceとsource

href = Hypertext Reference、src = source

hrefはHypertext Referenceの略で、referenceは「参照」という意味です。「参照する先はどこ？」と結び付けると覚えやすくなります。

srcはsourceの略で、sourceは「元・出どころ」という意味です。「この画像やプログラムの出どころはどこ？」と読んでみましょう。

<a href="...">：クリックしたときの移動先

トップページへ戻るリンクの例です。

<a href="../index.html">トップへ戻る</a>

<a>はリンクを表すタグです。この例では「トップへ戻る」という文字をクリックすると、hrefで指定した../index.htmlへ移動します。

ここでは「href = リンク先」という理解で十分です。表示する文字と、移動先の場所は別々に書かれています。

<link href="...">：CSSの参照先

次は、ページの見た目を決めるCSSを指定する例です。

<link rel="stylesheet" href="../assets/styles.css">

rel="stylesheet"は「見た目を指定するスタイルシートとの関係」を表し、hrefがそのファイルの場所を示します。「このCSSファイルを参照して、見た目を整える」と読めます。

この行はクリックするリンクではありません。ブラウザがCSSを読み込み、ページに適用します。そのため、hrefは単なる「クリック先」よりも、広く「参照先」と覚える方が読み違えにくくなります。

<img src="...">：画像の読み込み元

画像をページに表示する例です。

<img src="../assets/koi.png" alt="">

<img>は画像のタグです。srcで指定した場所から画像ファイルを読み込み、このページ内に表示します。

「画像の出どころは../assets/koi.png」と読めば、sourceの意味とつながります。この例のalt=""は、装飾用の画像として代替テキストを空にしています。

<script src="...">：JavaScriptの読み込み元

こちらは説明用の例です。同じフォルダにapp.jsというJavaScriptファイルがあると仮定しています。このサイトに実在するファイルではありません。

<script src="app.js"></script>

「app.jsを読み込んで、このページで実行する」と読みます。そのファイルをページ内で使うために読み込むので、ここではsrcを使います。

画像なら表示するため、JavaScriptなら処理を動かすため。読み込んだ後の使い方は違っても、「読み込み元を示す」という役割は同じです。

hrefとsrcを並べて比べる

href：参照先

よく使うタグ：<a>、<link>
「どこへ行く？」「何を参照する？」と読む。referenceの「参照」が手がかり。

src：読み込み元

よく使うタグ：<img>、<script>
「何をここへ読み込む？」と読む。sourceの「出どころ」が手がかり。

どちらの値にもURLやファイルの場所が入ります。場所の文字列だけで判断せず、<a>なのか<img>なのか、左側のタグも一緒に見ると役割が分かります。

このサイトのコードを読んでみる

このサイトの記事ページにも、次の指定があります。別々の場所にある行を抜き出し、画像のクラスやサイズ指定は省略しています。

<link rel="stylesheet" href="../assets/styles.css">
<img src="../assets/koi.png" alt="">
<a href="../index.html">← トップページへ戻る</a>
  • <link>：共通CSSのstyles.cssを参照し、見た目を整える。
  • <img>：錦鯉の画像koi.pngを読み込み、表示する。
  • <a>：クリックしたらトップページのindex.htmlへ移動する。

この3行を見て「CSSの場所」「画像の場所」「戻る先」が分かれば、全部の書き方を暗記しなくても、コードの意味を追えています。

../は「1つ上のフォルダへ」

hrefやsrcの中にある../は、この例では「1つ上のフォルダへ戻る」という意味です。記事が入っているarticlesフォルダから1つ上へ戻り、assetsやindex.htmlを探しています。

こうした場所の書き方を「相対パス」と呼びます。詳しくは「相対パスとは？ ../ の意味を読めるようになる」で説明しています。今回は、hrefとsrcのどちらにも同じ場所の書き方が使える、と分かれば大丈夫です。

参考：MDNのlink要素の説明でも、CSSなど外部リソースとの関係を指定する役割を確認できます。

今日覚えること

hrefは参照先（<a>・<link>）、srcは読み込み元（<img>・<script>）です。

迷ったら、referenceは「参照」、sourceは「元・出どころ」を思い出し、タグと一緒に読みましょう。
