トップ › if文とは？

if文とは？ 条件分岐を最低限だけ理解する

ifは「もし〜なら」。条件に合うかどうかで、実行する処理を選ぶための書き方です。

「もし点数が80点以上なら合格と表示する」のように、状況に応じて作業を変えたいことがあります。 コードでこの判断を書くのがif文です。条件によって処理の進み方を分けることを「条件分岐」と呼びます。

if：条件が真なら処理を実行する

if の後ろの丸かっこに条件を書き、{ と } の間に処理を書きます。 条件が成り立つことを「真（true）」、成り立たないことを「偽（false）」といいます。 条件が真なら中の処理を実行し、偽ならその処理を飛ばします。

条件の読み方

例えば score >= 80 は「点数が80以上」という条件です。 >= は「以上」を表すので、80点ちょうども含まれます。 点数が85なら真、75なら偽になります。

名前の由来：if・else

if は英語の「もし〜なら」です。「もし条件に合うなら、この処理をする」と読むと、コードの流れをつかめます。

else は英語で「それ以外に」を表す言葉です。if文では「それ以外なら」と読むと、役割を覚えやすくなります。

else：「それ以外なら」の処理

else は、ifの条件が偽だった場合の処理を書くために使います。 「もし80点以上なら合格、それ以外なら復習」のように、2つの道に分けられます。 else 自体には条件を書きません。

条件に合わないときに何もしなくてよければ、else は省略できます。 その場合はifの中を飛ばして、if文の後にある処理へ進みます。

else if：判断する条件を追加する

3通り以上に分けたいときは、else if を使います。 「前の条件には合わなかったけれど、もし次の条件に合うなら」と読めます。 必要に応じて複数の条件を追加できます。

条件は上から順番に確認され、この一続きのif・else if・elseの中では、最初に合った1つの処理だけが実行されます。 どの条件にも合わなければ、最後の else の処理を実行します。

GASの例：点数に応じたメッセージを表示する

Google Apps Script（GAS）で、点数に応じて実行ログにメッセージを表示してみます。 80点以上は「合格」、60点以上80点未満は「あと少し」、60点未満は「復習しましょう」と表示する例です。 

function main() {
  const score = 75;

  if (score >= 80) {
    Logger.log("合格");
  } else if (score >= 60) {
    Logger.log("あと少し");
  } else {
    Logger.log("復習しましょう");
  }
}

GASのエディタに貼り付けて保存し、実行する関数として main を選んで実行してください。 実行ログ（結果などを確認するための記録）に「あと少し」と表示されます。 Logger.log が、丸かっこの中のメッセージをログに表示する処理です。

  1. score に75を入れます。
  2. 75は80以上ではないので、最初のifの条件は偽となり、「合格」の表示を飛ばします。
  3. 75は60以上なので、else ifの条件は真となり、「あと少し」を表示します。
  4. 処理が1つ選ばれたため、最後のelseは実行しません。

数字を変えて確認する

コードの 75 を 80 に書き換えて再実行すると「合格」、 60 なら「あと少し」、59 なら「復習しましょう」と表示されます。 境目の数字で試すと、「以上」にその数字が含まれることを確認できます。

条件の順番にも意味があります。先に「60以上」を調べると、80点もその条件に合います。 この例では高い点数から確認することで、表示を正しく分けています。

AIに条件分岐を頼むときは

「80点以上なら合格、60点以上80点未満ならあと少し、それ以外は復習と表示して」のように、 条件と処理をセットで伝えましょう。「80点ちょうどはどちらに入るか」まで決めると、意図が伝わりやすくなります。

今日覚えること

ifは「もし〜なら」で、条件が真のときに処理を実行します。elseは「それ以外なら」、else ifは「別の条件も調べる」と覚えましょう。
