for・forEachとは？ 同じ処理を繰り返す

JavaScriptやGASのコードを読んでいると、for や forEach という言葉が頻繁に出てきます。これらは繰り返し処理（ループ / loop）を行うための仕組みで、特に配列の中に並んだデータを1個ずつ順番に処理したいときに大活躍します。

1. まず結論：同じような処理を何度も繰り返すための仕組み

初心者の方は、まずこれだけ覚えておけば十分です。

for と forEach の役割

同じような処理を何度も繰り返す命令。特に「配列の中身を1個ずつ順番に取り出して処理する」ときに最もよく使われます。

例えば、100人分のメールを順番に送ったり、スプレッドシートの行を1行ずつチェックしたりするとき、100行も同じコードを手書きするのは大変です。forEach や for を使えば、数行書くだけで自動的に全部のデータを回してくれます。

2. まず読みやすい forEach から見てみよう

JavaScriptにはいくつか繰り返しの書き方がありますが、AIが書く現代のコードでは forEach の方が直感的で読みやすいので、こちらから先に見てみましょう。

const fruits = ["apple", "banana", "orange"];

fruits.forEach(fruit => {
  Logger.log(fruit);
});

細かい記号は後で説明します。まずはこのコード全体を見て、次のようにざっくり読めれば完璧です。

「fruits の中身を1個ずつ取り出して、ログに表示しているんだな」

fruits.forEach(...) を見かけたら、「fruits の各要素（each）に対して同じ処理をしている」と受け止めてください。

3. fruit は取り出した1個の値につけた「一時的な名前」

丸っこの中の fruit に注目してみましょう。

fruits.forEach(fruit => {

この fruit は、配列から今まさに取り出している1個のデータに付けた名前（変数）です。

  • 1回目の繰り返し → fruit には "apple" が入る
  • 2回目の繰り返し → fruit には "banana" が入る
  • 3回目の繰り返し → fruit には "orange" が入る

このように、中身が自動的に入れ替わりながら、{ } の中の処理が3回実行されます。

名前は何でもOK

fruit という名前は書いた人が自由に決めたものです。item でも f でも動きますが、AIは読みやすいように「複数形（fruits）から1個（fruit）を取り出す」という自然な名前を付けることが多いです。

4. => は何か？ 「この値を使って、この処理をする」の目印

fruit => { ... } にある => という記号は、JavaScriptのアロー関数（arrow function）と呼ばれる記号です。

矢印（アロー）の形をしていることからそう呼ばれますが、ここでは文法を難しく考える必要はありません。初心者の方は、

「左で取り出した値（fruit）を使って、右の波かっこ { } の処理を実行する」

という橋渡しの区切り記号として捉えておけば十分に読めます。

5. GASで一番よく見る例：getValues() と forEach

Google Apps Script（GAS）で最もよく登場するのが、スプレッドシートの表データを読み出してループするパターンです。

const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
const values = sheet.getDataRange().getValues();

values.forEach(row => {
  Logger.log(row[0]);
});

「配列 [] とは？」の記事で学んだ知識をつなげて、左から順番に分解してみましょう。

  1. getValues()：シートの複数セルをまとめて二次元配列として取得する
  2. values：行がズラリと並んだ配列
  3. .forEach(row => {：1行ずつ取り出し、その行を row と名付ける
  4. row[0]：その行の 0番目（A列・最初の列）の値を取り出してログに出す

「表全体のデータを取ってきて、1行ずつ上から順番にA列のデータを確認している」という全体の流れがくっきり見えてきます。

6. オブジェクトの配列との組み合わせ

前の記事「オブジェクト {} とは？」で学んだ、配列の中にオブジェクトが入っているデータも、forEach でよく処理されます。

const users = [
  { name: "Masa", age: 31 },
  { name: "Ken", age: 28 }
];

users.forEach(user => {
  Logger.log(user.name);
});

これも分解してみると非常にシンプルです。

  1. users：ユーザーのオブジェクトが並んだ配列
  2. user：取り出した1人分のオブジェクト（{ name: "Masa", age: 31 } など）
  3. user.name：その人の名前を取り出してログに出す

実行すると、ログには順番に "Masa"、"Ken" と表示されます。「配列から1人ずつ取り出して、その人の名前を読んでいる」と自然に読めますね。

7. 昔から使われる for文 とは？

forEach のほかに、昔からプログラミング全般で使われているのが for文 です。

for (let i = 0; i < 3; i++) {
  Logger.log(i);
}

丸かっこの中が少し暗号のように見えますが、細かい文法を暗記する必要はありません。まずはこれだけ分かれば合格です。

「i を 0から始めて、3未満の間、1ずつ増やしながら繰り返す」

実行すると、ログには 0、1、2 と順番に出力されます。

8. 変数 i とは？ 「現在の回数・番号」

for文で必ずと言っていいほど出てくる i は、繰り返し回数（カウント）や配列のインデックス番号を表すためによく使われる変数名です。

英語の index（添字・見出し） や iteration（反復） の頭文字から取られた慣習で、プログラミング界の定番の文字です。

9. i++ とは？ 「i を 1増やす」

for文の末尾にある i++ は、「i の値を 1増やす」という意味の書き方です（インクリメントと呼びます）。

処理が1回終わるたびに i++ が実行され、i が 0 → 1 → 2 と増えていきます。

10. 配列を for文 で読む

配列の中身を for文 で順番に取り出すときは、次のように書かれます。

const fruits = ["apple", "banana", "orange"];

for (let i = 0; i < fruits.length; i++) {
  Logger.log(fruits[i]);
}

「配列」の記事で学んだパーツが総動員されていますね。

  • fruits.length：配列の個数（ここでは 3）
  • let i = 0; i < fruits.length：番号 0 から始めて、3未満（0, 1, 2）まで回す
  • fruits[i]：配列の i番目の要素を取り出す（fruits[0], fruits[1], fruits[2]）

これで、配列の先頭から末尾までキレイに順番通り取り出すことができます。

11. for と forEach の違い：どちらを使えばいい？

AIが生成するコードを見ていると、for も forEach も両方出てきます。初心者のうちは、次のイメージを持っておくだけで十分です。

forEach

配列を1個ずつ順番に処理したいときにシンプルで読みやすい。現代のJavaScriptやGASで主流。

for

「3回だけ繰り返したい」「2個飛ばしで進めたい」「途中でループを中断したい」など、回数や番号を細かくコントロールしたいときに使う。

「どちらが優れている」というものではなく、場面によって使い分けられています。自分で選んで書けなくても、コードを見たときに「あ、どちらも繰り返しをしているんだな」と気づければバッチリです。

12. コードを読むときのコツ

コードの中でループ処理を見かけたら、次のポイントに注目してみてください。

forEach を見かけたとき

  1. どの配列を処理しているか：xxx.forEach の xxx を見る
  2. 1個ずつ取り出した値の名前は何か：(item => の item を見る
  3. 波かっこ { } の中で何をしているか：取り出した値を使って何を実行しているか追う

for を見かけたとき

  1. どこから始まるか：let i = 0 などを確認
  2. どこまで続けるか：i < xxx.length などの終了条件を確認
  3. 波かっこ { } の中で何をしているか：array[i] で何を取り出しているか確認
今日覚えること
  • for と forEach は、同じような処理を何度も繰り返す仕組み
  • forEach は、配列の中身を1個ずつ順番に処理するときによく使う
  • array.forEach(item => { ... }) を見たら「各 item に対して処理」と読む
  • for文 は、回数やインデックス番号を使って細かく制御したいときに使う
  • i++ は「i を 1増やす」合図
  • GASでは getValues() で取得した表データを forEach で1行ずつ回すのが鉄板パターン
