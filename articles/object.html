オブジェクト {} とは？ 名前を付けて値をまとめる

JavaScriptやGASのコードを読んでいると、波かっこ { } の中に「名前: 値」が並んだ記述がよく登場します。これはオブジェクト（object）と呼ばれ、関連する情報に名前を付けてひとまとめに管理するための仕組みです。

1. まず結論：オブジェクトは「複数の値に名前を付けてひとまとめにするもの」

初心者の方は、まずこの一言だけ覚えておけば十分です。

オブジェクト（object）の役割

複数のデータに名前（キー）を付けて、1つの変数に整理してまとめておく箱。

例えば、あるユーザーの情報をまとめたいときは次のように書きます。

const user = {
  name: "Masa",
  age: 31,
  city: "Tokyo"
};

name、age、city という名前を付けて、それぞれの値を1つの変数 user にまとめています。別々に userName、userAge、userCity と3つ変数を作らなくても、1人の情報として整理できるのがオブジェクトの便利さです。

2. 配列との違い：配列は「順番」、オブジェクトは「名前」

前の記事「配列 [] とは？」で、複数の値をまとめる箱として配列を学びました。では、配列とオブジェクトはどう使い分けるのでしょうか？

同じユーザー情報を配列で書くとこうなります。

const userArray = ["Masa", 31, "Tokyo"];

この場合、中身を取り出すには 「順番（インデックス番号）」 を指定します。

const name = userArray[0]; // 0番目（Masa）を取り出す
const age = userArray[1];  // 1番目（31）を取り出す

一方、オブジェクトの場合は 「名前（キー）」 で取り出します。

const user = {
  name: "Masa",
  age: 31,
  city: "Tokyo"
};

const name = user.name; // "name" という名前で取り出す
const age = user.age;   // "age" という名前で取り出す

「1番目が年齢で、2番目が都市だっけ……？」と順番を覚える必要がなく、名前で中身がすぐ分かるのがオブジェクトの強みです。

覚え方のコツ

配列 [ ] ＝ 順番で管理する（0番、1番、2番……）
オブジェクト { } ＝ 名前で管理する（name、age、city……）

3. { } を見たらオブジェクトを疑う（ただし例外あり）

JavaScriptのコードで、次のような { } を見かけたら、まず「オブジェクトかもしれない」と疑ってみてください。

{
  key: value
}

ただし、波かっこ { } はプログラミングの中で複数の役割を持っています。すでに学んだ function や if文 の処理ブロックも { } を使います。

// これはオブジェクトではなく、if文の処理のまとまり
if (score >= 80) {
  Logger.log("合格です");
}

「中に 名前: 値 が並んでいるか？」 を見るのが見分けるポイントです。コロン : で結ばれた項目が並んでいれば、ほぼ確実にオブジェクトです。

4. key: value（キーと値）の形

オブジェクトの中身は、必ず「キー（key）」と「値（value）」のペアで書かれます。

name: "Masa"
  • キー（key）：項目の名前（ここでは name）
  • コロン（:）：キーと値を結ぶ区切り
  • 値（value）：その項目の中身（ここでは "Masa"）

コードを読むときは難しく考えず、「name という項目に "Masa" という値が入っている」と読めれば十分です。このキーと値の組み合わせのことを「プロパティ（property）」と呼ぶこともあります。

5. 複数の項目はカンマで区切る

オブジェクトの中に複数の項目を並べるときは、配列と同じようにカンマ（,）で区切ります。

const user = {
  name: "Masa",
  age: 31,
  active: true
};

最後の項目の後ろのカンマは、あってもなくても動きますが、AIが書くコードでは改行してきれいに並べられるのが一般的です。

6. ドット（.）で値を読む：「user の name」

オブジェクトの中にある特定の値を取り出すときは、.（ドット）を使います。

Logger.log(user.name); // ログに "Masa" と表示される

「. と () は何？」の記事で学んだように、ドットは「左のものの中にある右のもの」を取り出す記号でした。ここでもまったく同じです。

user.name は、左から順に「user の中の name」と読むとすんなり理解できます。

7. [ ] を使って読むこともある

実は、角かっこ [ ] を使ってオブジェクトの値を読む書き方もあります。

const userName = user["name"]; // user.name と同じ "Masa" が取れる

キー名を変数で動的に切り替えたい場面などで使われますが、初心者の方はまず基本である user.name のドット記法が読めれば十分です。「こういう書き方もあるんだな」程度に捉えておいてください。

8. 値を書き換える

オブジェクトの中の値は、後から書き換えることもできます。

user.age = 32;

これも左から読みます。「user の age に 32 を入れる」という意味です。この一行が実行されると、user.age は 31 から 32 に更新されます。

9. 新しい項目を追加する

最初にはなかった項目を、後から追加することもできます。

user.email = "example@example.com";

「user に email という新しい項目を作って、アドレスを入れる」という処理です。自分でゼロから書く必要はありませんが、AIが生成したコードでこの形を見かけたら「あ、後から項目を増やしているんだな」と読めればバッチリです。

10. GASでオブジェクトが出てくる例

Google Apps Script（GAS）では、オブジェクトが非常に重要な場面で登場します。特に多いのが「複数の設定や情報をまとめて渡す場面」です。

// カレンダーの予定情報やメールのオプションをまとめる例
const event = {
  title: "定例会議",
  date: "2026-09-28",
  location: "オンライン"
};

また、前の記事「returnとは？」とつながる重要なパターンとして、function の実行結果をオブジェクトで返す書き方があります。

function sendDailyReport() {
  // メール送信などの処理...

  return {
    success: true,
    message: "日報を送信しました"
  };
}

const result = sendDailyReport();
Logger.log(result.success); // true
Logger.log(result.message); // "日報を送信しました"

return は通常1つの値しか返せませんが、オブジェクトにまとめれば「成否」と「メッセージ」のように複数の結果をひとまとめにして呼び出し元へ戻すことができます。

11. JSONとのつながり：見た目は似ているが別物！

このサイトの「JSONとは？」を読んだことがある方は、「あれ？ JSONとそっくりだな」と思ったかもしれません。

確かに、JavaScriptのオブジェクトとJSONの書き方は非常によく似ています。

// JavaScriptのオブジェクト
const user = {
  name: "Masa",
  age: 31
};

// JSONのデータ形式（文字列）
{
  "name": "Masa",
  "age": 31
}

しかし、JavaScriptのオブジェクトとJSONは同じものではありません。オブジェクトはプログラムの中で動いている「データそのもの」であり、JSONはインターネットなどでデータをやり取りするための「テキスト形式（文字列のルール）」です。JSONではキーを必ずダブルクォーテーション " " で囲むなどの厳密なルールがあります。

詳しい違いは JSONとは？ で解説していますので、気になる方は合わせて確認してみてください。

12. オブジェクトの中に配列：user.skills[0]

実務のコードでとてもよく出てくるのが、オブジェクトの中に配列が入っている構造です。

const user = {
  name: "Masa",
  skills: ["HTML", "CSS", "JavaScript"]
};

このデータから「HTML」を取り出したいとき、コードでは次のように書かれます。

Logger.log(user.skills[0]); // "HTML"

一見ややこしそうに見えますが、左から順番に分解すれば怖くありません。

  1. user：ユーザーのオブジェクト
  2. .skills：その中にある skills（配列）を取り出す
  3. [0]：その配列の先頭（0番目）の値を取り出す

左から順にたどっていけば、AIが書いた複雑なコードでも必ず意味を追えます。

13. 配列の中にオブジェクト：users[0].name

今度は逆のパターンです。配列の中に複数のオブジェクトが入っている構造も、スプレッドシートやAPIのデータを扱うときによく登場します。

const users = [
  { name: "Masa", age: 31 },
  { name: "Ken", age: 28 }
];

この一覧から最初の人の名前を取り出すときは、次のように書きます。

Logger.log(users[0].name); // "Masa"

これも左から落ち着いて分解してみましょう。

  1. users：オブジェクトが並んだ配列
  2. [0]：その配列の最初（0番目）の要素（{ name: "Masa", age: 31 }）
  3. .name：そのオブジェクトの中の name（"Masa"）

「配列（番号）」と「オブジェクト（名前）」が組み合わさっているだけだと分かれば、AIのコードに出てきても落ち着いて読み解くことができます。

14. コードを読むときのコツ

コードの中で波かっこ { } を見かけたら、次のステップで観察してみてください。

  1. key: value が並んでいるか確認：コロン : があればオブジェクトです（ifやfunctionの処理ブロックと見分ける）。
  2. どんなキー（項目名）があるか見る：name、date、title など、どんな情報をまとめているか把握します。
  3. .name のようにどの項目を読んでいるか追う：ドットの後ろを見て、どの値を使おうとしているか確認します。
  4. 配列 [ ] と組み合わさっていないか見る：user.skills[0] や users[0].name のように入れ子になっているときは、左から1段階ずつ分解します。
  5. return { ... } がないか見る：関数の末尾にあれば、複数の結果をひとまとめにして返している合図です。
今日覚えること
  • オブジェクトは、複数の値に名前を付けてひとまとめにする箱
  • { key: value } の形で書く（keyは項目名、valueは中身）
  • 配列は「順番」、オブジェクトは「名前」で値を管理する
  • user.name のようにドット（.）で値を取り出す
  • { } はifやfunctionでも使われる（: があるかでオブジェクトを見分ける）
  • オブジェクトの中に配列を入れることもできる（user.skills[0]）
  • 配列の中にオブジェクトを入れることもできる（users[0].name）
  • 複数の結果をまとめて return するときにも重宝される
