HTML・CSS・JavaScriptの違い

まずは「内容」「見た目」「処理」の役割分担が分かれば大丈夫です。

Webページのコードを見ると、HTML、CSS、JavaScriptという名前が出てきます。 この3つは、ブラウザに別々の指示を伝えるためのものです。 全部の書き方を覚える前に、それぞれが何を担当するのかを押さえましょう。

HTML：何を載せるかを決める

HTMLは、ページの内容と構造を表します。 「ここは見出し」「ここは文章」「ここはリンク」という意味を、タグと呼ばれる目印で伝えます。

例えば、<h1>今日のおすすめ</h1> は、 「今日のおすすめ」という文字が大きな見出しであることを表します。 <p> は段落、<a> はリンクを作るときに使います。

このサイトでは、トップページの index.html に、 サイト名や紹介文、記事へのリンクが書かれています。文章を変えたいときは、HTMLが主な変更先です。

英語から覚える：HTML

HTMLはHyperText Markup Languageの略です。HyperTextはリンクでつながる文章、Markupは見出しや段落などの目印を付けること、Languageは言語を意味します。「文章に意味や構造の目印を付ける」と覚えると、役割がつかめます。

CSS：どう見せるかを決める

CSSは、ページの見た目を整えます。 文字の色や大きさ、背景、余白、横に並べるか縦に並べるか、といった指定を担当します。

例えば、h1 { color: blue; } は、 「h1の見出しの文字を青くする」という意味です。同じ文章でも、CSSを変えると印象が変わります。

このサイトでは、assets/styles.css を各ページが共通で読み込んでいます。 記事の文字や余白がそろっているのは、そのためです。 スマートフォンの画面幅に合わせて、カードの並び方を変える設定もCSSにあります。

英語から覚える：CSS

CSSはCascading Style Sheetsの略です。Style Sheetsは見た目の指定をまとめたもの、Cascadingは「段々に流れ落ちる」というイメージの言葉です。CSSでは、複数の指定が重なったときに、決まったルールでどれを使うかを選びます。

JavaScript：操作に応じて処理する

JavaScriptは、計算や、操作に応じた内容の更新などを行うプログラミング言語です。 例えば、入力した金額から合計を計算したり、検索欄の文字に合う記事だけを表示したりできます。

「ボタンが押されたら、入力値を読み取り、計算して、結果を書き換える」のように、 何をきっかけに何をするかを指定します。別のファイルに分ける場合は、通常 .js という拡張子を使います。

ただし、すべての動きにJavaScriptが必要なわけではありません。 リンクを押して別のページに移動するのはHTMLの機能ですし、マウスを重ねたときの色の変化はCSSで指定できます。 現在のこのサイトは、HTMLとCSSだけで表示でき、JavaScriptは使っていません。

英語から覚える：JavaScript

Scriptには「台本」という意味があり、処理の手順を書くものと結び付けると覚えやすくなります。JavaScriptとJavaは名前が似ていますが、別のプログラミング言語です。

「料金の計算ページ」なら、どう分担する？

数量を入力して合計金額を表示するページを作るとしたら、次のように役割を分けられます。

  • HTML：商品名、数量の入力欄、計算ボタン、結果を表示する場所を用意する。
  • CSS：入力欄を見やすい幅にし、ボタンの色や余白を整える。
  • JavaScript：ボタンが押されたら単価と数量を掛けて、合計金額を表示する。

HTMLで用意した部品をCSSで整え、JavaScriptで必要な処理を加える、と考えるとつながりが分かります。 記事を読むだけのページなら、このサイトのようにHTMLとCSSだけでも作れます。

AIに修正を頼むときの伝え方

役割の違いが分かると、変えたい部分を具体的に伝えやすくなります。

  • 文章を変えたい：「HTMLの見出しを『今週のおすすめ』に変更してください」
  • 見た目を変えたい：「CSSで記事の文字を少し大きくし、行間を広げてください」
  • 処理を加えたい：「JavaScriptで、入力した数量から合計金額を計算して表示してください」

どの技術を使うか迷ったら、「何をしたときに、どうなってほしいか」を伝えれば大丈夫です。 新しい機能では複数のファイルを変更することもあるので、 「変更したファイルと、それぞれの役割も説明してください」と添えると理解しやすくなります。

今日覚えること

HTMLは「内容と構造」、CSSは「見た目」、JavaScriptは「計算や操作に応じた処理」。まずは、この役割分担が分かれば十分です。
