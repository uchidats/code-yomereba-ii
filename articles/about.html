このサイトについて

プログラマーになるつもりはない。でも、AIを使って実用的なものは作りたい。

ChatGPTなどの生成AIを使うようになってから、Webアプリや業務の自動化を自分でも作れる場面が増えてきました。 Google Apps Script（GAS）を使えばGoogleカレンダーやGmailを連携できますし、 HTMLやJavaScriptを使えば簡単なWebアプリも作れます。

ただし、AIがコードを書いてくれるようになっても、 「functionとは何か」「HTMLとCSSは何が違うのか」「APIとは何か」 「GitHubのcommitとは何か」といった言葉をまったく知らないままだと、 修正を頼むときに少し困ります。

一方で、プログラミングを一から体系的に勉強して、 すべてのコードを自分で書けるようになる必要があるとも感じません。

コードを全部書けなくてもいい。
何をしているのか大まかに読めて、AIに適切に指示できればいい。

このサイトは、そのための学習ノート兼備忘録です。 プログラマーになるためではなく、 AIに開発を任せるために最低限知っておきたいことだけを整理していきます。

扱うテーマ

  • HTML / CSS / JavaScriptの最低限
  • Google Apps Script（GAS）
  • CodexなどのAIコーディングツール
  • Git / GitHub
  • Webアプリやホームページ制作の実践記録
英語から覚える：GAS

GASは、Google Apps Scriptの頭文字を取った呼び方です。「Googleのサービスで使う処理を書く仕組み」と結び付けて覚えると、用途を思い出しやすくなります。

このサイトで目指さないこと

網羅的なプログラミング教材にはしません。 難しい理論を詳しく説明することも目的ではありません。 「この言葉が分かればAIとの会話が楽になる」 「ここだけ理解すれば次に進める」という実用性を優先します。

今日覚えること

AI時代には「全部書ける」より、「読める・指示できる」が大きな武器になる。
