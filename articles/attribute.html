属性とは？ class・id・href・src をまとめて理解する

HTMLのタグ名の後ろに続く class="nav-link" や href="../index.html" は、タグに追加情報を与える「属性」です。この記事では属性の読み方と、よく使う属性をまとめて整理します。

HTMLのコードを見て、こんな疑問を持ったことはないでしょうか。

<a class="nav-link" href="../index.html">トップへ戻る</a>

どこまでがタグ名で、どこからが別の情報なのか――。タグ名の後ろに付いている追加情報を、属性（attribute）と呼びます。

属性とは？

英語から覚える：attribute（属性）

attribute は「属性」「特徴」「性質」などを意味する英単語です。「そのタグが持っている特徴・追加情報」と結び付けると覚えやすくなります。

HTMLでは、属性はタグに追加情報を与えるものです。次の例を見てください。

<a href="https://example.com">リンク</a>
  • a：タグ名（リンクを表す）
  • href：属性名（どこへ移動するかを示す）
  • "https://example.com"：属性値（実際の移動先）

タグ名だけでは「リンクがある」としか分かりません。属性があることで「このリンクはどこへ向かうのか」という追加情報が伝わります。

属性は、「HTMLタグとは？」でも触れています。この記事では各属性をより詳しく整理します。

属性名と属性値

属性は 属性名 = "属性値" の形で書きます。

class="card"
  • class：属性名
  • "card"：属性値

= は「この属性にはこの値を指定している」くらいの意味で読んでください。属性値は必ず引用符（"）で囲みます。

1つのタグに複数の属性を付けられる

属性はスペースで区切って、いくつでも並べられます。

<a class="nav-link" href="../index.html">トップへ戻る</a>
  • a：タグ名
  • class：属性名 → "nav-link"：属性値
  • href：属性名 → "../index.html"：属性値

このように、1つのタグに class と href の2つの属性が付いています。属性はスペースで区切られ、順番に意味を持っています。

class

<div class="card">

class は要素をグループ分けするための属性です。同じ class 名を複数の要素に付けられ、CSSで見た目を指定したり、JavaScriptから対象を探したりするときによく使います。

詳しい使い方と id との違いは、「classとidの違い」で読めます。

id

<section id="start">

id はページ内で特定の要素を識別するための属性です。同じページに同じ id 値を重複させないルールがあります。CSSでその要素のスタイルを指定したり、href="#start" でページ内の特定の場所へリンクしたりするときに使います。

英語から覚える：id = identifier（識別子）

identifier は「見分けるための名前」という意味です。「ページの中でこの要素だけを特定する名前」と覚えると読みやすくなります。

class との詳しい違いは「classとidの違い」をご覧ください。

href

<a href="../index.html">トップへ戻る</a>

href はリンク先を指定する属性です。a タグに付けて「クリックしたときにどこへ移動するか」を伝えます。

英語から覚える：href

Hypertext Reference の略と説明されることが多く、reference は「参照」という意味です。「参照先・移動先」と結び付けて読みましょう。

詳しい使い方は「hrefとsrcの違い」で説明しています。

src

<img src="../assets/koi.png" alt="">

src は画像やスクリプトなど、読み込むファイルの場所を指定する属性です。img タグでは「どの画像を表示するか」、script タグでは「どのJavaScriptファイルを読み込むか」を伝えます。

英語から覚える：src = source（元・出どころ）

source は「元・出どころ」を意味します。「この画像はここから持ってくる」と読むと分かりやすくなります。

詳しい使い方は「hrefとsrcの違い」で説明しています。

alt

<img src="../assets/koi.png" alt="鯉のロゴ">

alt は画像の代替テキストを指定する属性です。画像が読み込めないときに代わりに表示されたり、スクリーンリーダー（視覚に障害のある方が使う読み上げツール）で内容を伝えたりするために使います。

英語から覚える：alt = alternative（代わりの）

alternative は「代わりの・別の選択肢」という意味です。「画像が見えないときの代わりのテキスト」と覚えましょう。

このサイトのロゴ画像のように、装飾目的の画像では alt="" と空にすることもあります。

このサイトのコードを実際に読む

このサイトの各ページのヘッダーには、次のコードがあります。

<img class="site-logo" src="../assets/koi.png" alt="" width="1148" height="1371">

分解してみましょう。

  • img：タグ名（画像を表す）
  • class：属性名 → "site-logo"：属性値（グループ名）
  • src：属性名 → "../assets/koi.png"：属性値（画像の読み込み元）
  • alt：属性名 → ""：属性値（装飾画像のため空）
  • width・height：属性名 → 画像のサイズを指定する属性

1つの開始タグの中に複数の属性がスペースで区切られて並んでいます。それぞれが「この画像タグへの追加情報」です。

属性はタグによって使えるものが違う

属性とタグには組み合わせのルールがあります。主なものだけ覚えておけば十分です。

  • href は主に a タグで使う
  • src は img や script などで使う
  • alt は img タグで使う
  • class や id はほぼすべてのHTML要素で使える

「a タグに src を書いても意味がない」という感覚が持てれば、コードを読むときに属性の用途を自然に整理できるようになります。

HTMLを読むときの順番

実際のコードを読むとき、次の順番で見るとスムーズです。

<a class="nav-start" href="#start">はじめに</a>
  1. タグ名を見る：a → リンクを表す
  2. 属性名を見る：class、href
  3. 属性値を見る："nav-start"（グループ名）、"#start"（移動先）
  4. 表示内容を見る：「はじめに」

「aタグなのでリンク。classはnav-start。hrefは#startへの移動先。表示される文字は『はじめに』」と読めれば十分です。ゆっくりで大丈夫です。

属性とCSSの関係

class や id は、CSSで見た目を指定するときにも使われます。

.card {
  padding: 16px;
  border: 1px solid #ccc;
}

CSSの .card は「classがcardの要素にこの見た目を適用する」という意味です。HTMLで付けた class="card" と、CSSの .card がつながっています。詳しいCSSセレクタの読み方（.class と #id の使い分けなど）は、今後の記事でまとめる予定です。

今日覚えること
  • タグ名の後ろに付く追加情報を属性と呼ぶ
  • class="card" では class が属性名、"card" が属性値
  • 1つのタグに複数の属性を付けられる（スペースで区切る）
  • class・id・href・src・alt はすべて属性
  • HTMLを読むときは「タグ名 → 属性名 → 属性値 → 表示内容」の順に見ると分かりやすい
