配列 [] とは？ 複数の値をまとめて扱う

JavaScriptやGASのコードを読んでいると、角かっこ [ ] で囲まれたデータがよく登場します。これは配列（はいれつ / array）と呼ばれ、たくさんのデータを1つのまとまりとして扱うための仕組みです。

まず結論：配列は「複数の値をひとまとめにする箱」

初心者の方は、まずこれだけ覚えておけば十分です。

配列（array）の役割

複数のデータ（文字列や数値など）を、順番に並べて1つの変数にまとめておく箱。

例えば、果物の名前をまとめたいときは次のように書きます。

const fruits = ["apple", "banana", "orange"];

"apple"、"banana"、"orange" という3つの文字列を、fruits という1つの変数にまとめて保管しています。別々に変数を3つ作らなくても、1つの箱で管理できるのが配列の便利なところです。

英語から覚える：array（整列・配列）

英語の array には「整然と並べる」「配置する」という意味があります。プログラミングでは、データが一列に順番通り並んでいる構造を指します。また、配列の中に入っている1つひとつのデータのことを「要素（ようそ / element）」と呼びます。

[ ] を見たら配列を疑う

JavaScriptのコードで、次のような角かっこを見かけたら、

[...]

まず「複数の値を並べた配列かもしれない」と考えましょう。

ただし、角かっこ [ ] は配列を作るだけでなく、後述するように fruits[0] のように「何番目の値を取り出すか」を指定するときにも使われます。この2つの使い方を押さえておくのがコードを読むポイントです。

配列の中身はカンマで区切る

配列の基本的な書き方はとてもシンプルです。

const numbers = [10, 20, 30];
  • [（角かっこ開き）で始まる
  • 値と値の間を ,（カンマ）で区切る
  • ]（角かっこ閉じ）で終わる

本棚に本を左から順番に並べていくようなイメージです。

番号は0から始まる（超重要）

配列を理解するうえで、最も重要でつまずきやすいのが「番号は0から数え始める」というプログラミングのルールです。

const fruits = ["apple", "banana", "orange"];

fruits[0]  // "apple"
fruits[1]  // "banana"
fruits[2]  // "orange"

人間の感覚では「1番目」と言いたくなりますが、コードの世界では「0番目」からスタートします。この番号のことを「インデックス（添字 / index）」と呼びます。

  • 最初の要素は [0]
  • 2番目の要素は [1]
  • 3番目の要素は [2]

「最初の値を取り出したいなら [0]」と覚えておきましょう。

配列の値を取り出す

配列の中から特定の値を取り出して、別の変数に保存することができます。

const firstFruit = fruits[0];

このコードは、

  1. fruits 配列の0番目（最初）の要素である "apple" を取り出す
  2. それを firstFruit という新しい変数に入れる

と読みます。変数の代入と同じルールです。

配列の個数を知る：.length

配列にデータが何個入っているかを知りたいときは、.length（レングス）を使います。

const fruits = ["apple", "banana", "orange"];
const count = fruits.length;  // 3

「. と () は何？」で学んだドットが使われています。「fruits の中の length（長さ・個数）」を取り出していると読めます。

なお、length は機能（関数）ではなく、配列が持っている情報（プロパティ）なので、末尾に () は付きません。

配列に追加する：.push()

あとから配列の末尾に新しいデータを追加したいときは、.push() をよく見かけます。

fruits.push("grape");

この命令を実行すると、fruits 配列の最後に "grape" が追加され、配列の中身は ["apple", "banana", "orange", "grape"] になります。

すべての操作を暗記する必要はありません。コードの中で .push(...) を見かけたら、「あ、配列に何か追加しているんだな」と読めれば十分です。

GASで配列がよく出る理由

GAS（Google Apps Script）のコードでは、配列が驚くほど頻繁に出てきます。その最大の理由は、Googleスプレッドシートのセルの値をまとめて読み書きするからです。

const values = sheet.getDataRange().getValues();

SpreadsheetAppでよく使われる getValues() という機能は、指定した範囲のセルに入っている値をすべてまとめて配列にして返してくれます。

そして、スプレッドシートは「行」と「列」が並ぶ表なので、GASでは「二次元配列（にじげんはいれつ）」という特別な形でデータが返ってきます。

二次元配列をやさしく説明

「二次元配列」と聞くと難しそうですが、要するに「配列の中に、さらに配列が入っている」だけです。

const values = [
  ["名前", "年齢"],
  ["Masa", 31],
  ["Ken", 28]
];

外側の [ ] の中に、各行を表す内側の [ ] がカンマ区切りで入っています。スプレッドシートの見た目そのままですね。

二次元配列から値を取り出すときは、角かっこを2つ並べて「何行目・何列目」と指定します（もちろん0から数えます）。

values[1][0];  // "Masa" （1行目の0列目）
values[1][1];  // 31     （1行目の1列目）

1つ目の [1] で「2番目の行（Masaの行）」を選び、2つ目の [0] で「その行の先頭（名前）」を取り出しています。

GASのコードを読んでいて values[i][0] のような書き方を見かけたら、「スプレッドシートの行と列からデータを取り出しているんだな」と理解できれば十分です。

returnとのつながり

前の記事「returnとは？」で学んだように、function は計算結果を外に返すことができます。配列も立派なデータなので、もちろん return できます。

function getMembers() {
  return ["Masa", "Ken", "Yuki"];
}

「複数の名前を配列にまとめて、関数の戻り値として外へ返している」と読めます。関数から複数のデータをまとめて受け取りたいとき、配列はとてもよく使われます。

配列の中身は同じ種類でなくてもよい

JavaScriptの配列には、文字列・数字・真偽値など、異なる種類のデータを混ぜて入れることも技術的には可能です。

const data = ["Masa", 31, true];

ただし実際の読みやすいコードでは、「果物の名前の一覧」「社員の年齢の一覧」のように、同じ種類のデータを並べて使うのが一般的です。

コードを読むときの4つのステップ

コードの中に [ ] を見かけたら、次の順番で目を動かしてみましょう。

const user = ["Masa", 31];
const name = user[0];
  1. 配列を作っているのか？：["Masa", 31] のように値を並べているなら、新しい配列の作成
  2. 値を取り出しているのか？：user[0] のように変数名の直後に付いているなら、要素の取り出し
  3. 番号（インデックス）を確認する：[0] は最初の要素、[1] は2番目
  4. 後ろに続く機能を見る：.length（要素数）や .push()（追加）が付いていないか確認する
今日覚えること
  • 配列は、複数の値をひとまとめにして扱う箱（[ ] で表す）
  • 中身の要素は 0番から始まる（最初の要素は [0]）
  • array[0] で特定の位置の値を取り出せる
  • .length で配列の中にある要素の個数が分かる
  • GASの getValues() はスプレッドシートを表す二次元配列を返す
  • function から配列をまるごと return して受け渡すこともできる
