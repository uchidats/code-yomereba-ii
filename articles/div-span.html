divとspanの違い｜HTMLの「まとまり」と「一部分」

divはひとかたまりを囲う「箱」、spanは文章などの一部分を囲う「部分的なマーカー」です。このサイトのヘッダーを例に、何をまとめているのか読んでみましょう。

まず結論：まとまりを囲うdiv、一部分を囲うspan

次は、タイトルと本文をまとめる説明用の例です。

<div class="card">
  <h2>タイトル</h2>
  <p>本文です。</p>
</div>

<div>から</div>までで、タイトルと本文を1つのカードとして囲っています。一方、文章の一部だけに目印を付けるなら、次のように読めます。

<p>これは<span class="important">重要</span>です。</p>

囲っているのは「重要」の2文字だけです。この例のimportantは説明用のclass名で、spanを付けただけでは色や太さは変わりません。見た目を変えるには、対応するCSSなどの指定が必要です。

英語から覚える：divisionとspan

divはdivision、spanは範囲

divはdivisionに由来し、divisionには「区分」「分割された部分」という意味があります。「ページの一区画」と結び付けると覚えやすくなります。

spanには「範囲」「広がり」、動詞では「一定の範囲を覆う」といった意味があります。「この範囲だけを囲う」という読み方の手がかりにしましょう。

divは複数の要素をひとまとめにする

このサイトの記事ページには、次の構造があります。画像のサイズ・class指定を省略し、サイト名と紹介文の中身は...で短くしています。

<div class="site-brand">
  <img src="../assets/koi.png" alt="">
  <div class="site-brand-text">
    <a class="site-title" href="../index.html">...</a>
    <p class="tagline">...</p>
  </div>
</div>

外側のsite-brandは、錦鯉画像とサイト名・紹介文をまとめたひとかたまりです。内側のsite-brand-textは、そのうち文字の部分をまとめています。

「大きな箱の中に、画像と文字用の箱がある」と読むと構造が見えてきます。divの中にdivを入れても構いません。閉じる</div>まで追うと、それぞれの箱の範囲が分かります。

spanは文章の一部分に目印を付ける

このサイトの紹介文には、実際に次のspanがあります。読みやすく改行して示しています。

<p class="tagline">
  <span class="tagline-extra">あとはAIに。</span>
  非エンジニアのためのAI開発・GAS・Codex入門
</p>

pが紹介文全体を囲み、その中の「あとはAIに。」だけをspanで囲っています。tagline-extraというclassを目印に、この部分だけをCSSから指定できます。

現在の共通CSSでは、画面幅600px未満でこの部分だけを非表示にしています。紹介文の残りはそのまま表示します。関連する指定だけを抜き出すと、次の形です。

@media (width < 600px) {
  .tagline-extra {
    display: none;
  }
}

「幅が600px未満なら、tagline-extraを表示しない」と読めます。span自体がスマホを判断するのではなく、spanに付けたclassをCSSが指定している、という関係です。

divとspanを並べて比べる

div：まとまりを作る箱

用途：複数の要素をまとめる
基本の表示：新しい行から始まる
よく使う場面：レイアウト、カード、グループ

span：一部分を囲う目印

用途：文章などの一部分を囲う
基本の表示：文中に続く
よく使う場面：文章の一部、装飾や操作の対象

これは通常の表示をもとにした比較です。実際の並び方は、CSSの指定によって変わります。

ブロックとインラインは、基本の並び方

divは「ブロック要素」、spanは「インライン要素」と説明されます。ここでは、標準の表示がブロックかインラインか、という感覚で読めれば十分です。

divは、基本的には親の横幅いっぱいを使う箱になり、新しい行から始まります。特別なCSSがなければ、次のAとBは縦に並びます。

<div>A</div>
<div>B</div>

spanは文章の流れの中に入り、囲った部分に沿って表示されます。次のAとBは、幅に余裕があれば同じ行に続きます。

<span>A</span>
<span>B</span>

ただし、divなら必ず縦、spanなら必ず横、とは限りません。CSSのdisplayなどで表示方法を変えられます。このサイトのsite-brandも、CSSで中の画像と文字を横に並べています。

要素とclassを分けて読む

「classとidの違い」では、classをグループ名として読みました。タグの種類と、そのタグに付けた名前を分けると、さらに読みやすくなります。

<div class="card">
  • div：まとまりを作るHTML要素。
  • class="card"：そのまとまりに付けたグループ名。
<span class="tagline-extra">
  • span：一部分を囲うHTML要素。
  • class="tagline-extra"：その部分に付けたグループ名。

divやspanは「どんな要素か」、classという属性は「どのグループか」を表します。名前だけを眺めるより、役割を分けて読む方が、CSSとのつながりも追いやすくなります。

divは意味を持たない？

divとspanは、特定の意味を持たない汎用的な要素です。「役に立たない」ということではなく、タグ自体は内容の役割まで説明しない、という意味です。

  • header：ページや区画のヘッダー。
  • nav：ナビゲーション。
  • article：記事など、独立した内容。
  • div：特別な意味を持たない、汎用的なまとまり。

内容に合う意味のあるタグが適切なら、そちらを使います。特に適切なタグがないとき、ひとまとめにするためにdivがよく使われます。spanも、文章内の範囲を汎用的に囲う役割です。

spanは、どんなときに使う？

文章の一部だけを対象に、次のようなことをしたい場面で使われることがあります。

  • CSSで色を変えたり、太字にしたりする。
  • スマホのときだけ非表示にする。
  • JavaScriptで一部分の内容を変える。

見た目を変えるたびに必ずspanが必要なわけではありません。既にある要素にCSSを指定できる場合もありますし、内容の重要性を示すならstrongのような意味のあるタグが適切な場合もあります。

よくある勘違いは、この3つ

  • 「divとspanは大きさだけが違う」：基本の表示や、囲う内容の種類が違います。文字が少ないから必ずspan、という選び方ではありません。
  • 「divの中にdivを入れてはいけない」：入れて構いません。site-brandのように、大きなまとまりの中をさらにまとめられます。
  • 「spanの中には何でも入れられる」：divや見出しなどを何でも入れられるわけではありません。基本的に文章などの小さな範囲に使う、と考えてください。

コードを読むときは、囲っている範囲を見る

<div class="site-brand">
<span class="tagline-extra">

それぞれの開始タグを、「site-brandという名前のまとまりが始まる」「tagline-extraという名前を付けた一部分が始まる」と読んでみましょう。

次に閉じるタグまで追い、何が中に入っているかを見ます。画像と文字なのか、短いひと言なのか。それが分かれば、なぜここを囲っているのかも見えてきます。

今日覚えること

divはまとまりを作る箱で基本はブロック、spanは一部分を囲う目印で基本はインラインですが、表示はCSSでも変わります。

classはその要素に付けるグループ名なので、コードでは「要素の種類」と「classの名前」を分けて読みましょう。
