returnとは？ functionの結果を返す

function（関数）のコードを読んでいると、最後のほうによく return という言葉が出てきます。return は、functionの中で作った「計算結果」や「データ」を外に渡すための仕組みです。

まず結論：returnは「結果を外に返す」もの

初心者の方は、まずこれだけ覚えておけば十分です。

return の役割

function の中で作った結果を、呼び出した外側のコードへ渡す（返す）。

functionを「作業をお願いする担当者」に例えるなら、頼まれた作業を終えたあと「結果はこれです！」と報告書を手渡してくれる動作が return です。

英語から覚える：return（戻す・返す）

英語の return には「戻る」「返す」「持ち帰る」という意味があります。プログラミングでは、functionが呼び出し元に返す結果のことを「戻り値（もどりち）」または「返り値（かえりち）」と呼びます。

最も単純な例：足し算の結果を返す

次のコードを見てみましょう。

function add(a, b) {
  return a + b;
}

このコードは、2つの数を受け取って足し算する関数です。

  • a + b で足し算を計算する
  • return でその計算結果を外へ渡す

例えば add(2, 3) を実行すると、2 + 3 が計算され、結果として 5 が外へ返ってきます。

returnがないとどうなる？

もし return を書かなかったらどうなるでしょうか。

function add(a, b) {
  a + b;
}

この場合、functionの中で a + b の計算は行われます。しかし、return がないため、計算した結果が外へ渡されません。

担当者に「2と3を足しておいて」と頼んで、担当者が頭の中で計算したものの、結果を誰にも言わずに作業を終えてしまったような状態です。外側から見ると、結果を受け取ることができません。

計算や処理の結果を外で使いたいときは、必ず return で外へ渡します。

変数に受け取る

return で返された結果は、変数に入れて取っておくのが一般的です。

const result = add(2, 3);

このコードは次のように読みます。

  1. 右側の add(2, 3) が実行される
  2. functionの中で 2 + 3 が計算され、return で 5 が返ってくる
  3. 返ってきた 5 が、左側の result という変数に入る

これで、その後の行で result という名前を使って 5 という値を自由に使えるようになります。

GASでよく見るreturn

Google Apps Script（GAS）のコードでも、return は頻出します。

function getSheet() {
  return SpreadsheetApp.getActiveSpreadsheet();
}

「. と () は何？」や「SpreadsheetAppとは？」で学んだ知識で分解してみましょう。

  • SpreadsheetApp.getActiveSpreadsheet()：現在開いているスプレッドシートを取得する
  • return：取得したスプレッドシートを、getSheet() の結果として外へ返す

「スプレッドシートを取得して、それを外に手渡す関数だな」と、構造をシンプルに理解できます。

returnを見たらどう読むか（重要）

コードの中に return を見かけたら、次のように読みましょう。

return something;

「このfunctionは something を結果として返す！」

function全体の処理が長くても、最後に return されているものを見れば、「結局この関数は何を作り出して渡してくれるのか」が分かります。return は、functionの結論を示す目印です。

returnが動くとfunctionはその場で終わる

もうひとつ大切なルールがあります。return が実行されると、そのfunctionの処理はそこで直ちに終了します。後ろにまだコードが残っていても実行されません。

if文と組み合わせた例を見てみましょう。

function checkAge(age) {
  if (age < 20) {
    return "未成年";
  }

  return "成人";
}

この関数は次のように動きます。

  • もし age が20未満なら、return "未成年"; が実行され、そこで関数は終了します。下の行の "成人" は見に行きません。
  • もし age が20以上なら、if文の中は通らず、最後の return "成人"; が実行されて "成人" を返します。

「条件に合ったら、そこで結果を返して終わりにする」という書き方は、プログラミングで非常によく使われます。

returnは何を返せる？

return の右側には、さまざまな種類のデータを置くことができます。

  • 数字：return 100;
  • 文字列：return "完了しました";
  • true / false：return true;
  • 配列（一覧データ）：return ["りんご", "みかん"];
  • オブジェクト（まとまりデータ）：return { name: "田中", age: 25 };

配列 [] やオブジェクト {} については今後の記事で詳しく扱いますが、「functionは数字だけでなく、文字でも一覧でも何でも返せる」と知っておけば十分です。

returnとconsole.logの違い

初心者の方が一番混乱しやすいのが、return と console.log（GASでの Logger.log）の違いです。

console.log(value);

画面やログに表示するだけ。
人間が確認するためのメモ書き。他のプログラムからはその値を使えません。

return value;

functionの結果として外へ渡す。
変数に入れたり、別の計算に使ったりできます。

「画面に表示して確認したいときは log、次の処理にデータを受け渡したいときは return」と区別しましょう。

コードを読むときの5つのステップ

function を見かけたら、次の順番で目を動かしてみましょう。

function getDiscountPrice(price) {
  if (price >= 1000) {
    return price * 0.9;
  }
  return price;
}
  1. function名を見る：getDiscountPrice（割引価格を計算する関数だな）
  2. 引数（材料）を見る：(price)（元の値段を受け取るんだな）
  3. 中身の処理を見る：if (price >= 1000)（1000円以上かチェックしている）
  4. return を探す：return price * 0.9; と return price; がある
  5. 何を返しているか確認する：条件に合えば1割引きの値段、そうでなければ元の値段を返している

このように「最後は何を返しているか（return）」に着目すると、途中の細かい計算に迷わされずに関数の目的をつかむことができます。

今日覚えること
  • return は、functionの中で作った結果を外へ返すもの
  • return の後ろにある値が、関数の「戻り値」になる
  • return が実行されると、そのfunctionの処理はそこで終了する
  • 返された結果は const result = add(2, 3); のように変数で受け取れる
  • コードを読むときは return を探すと、その関数の結論が分かる
