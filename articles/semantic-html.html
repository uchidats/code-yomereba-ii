header・nav・main・section・articleの違い｜HTMLの骨組みを読む

<header>・<nav>・<main>・<section>・<article>は、ページの中で「ここは何の役割か」を名前で示すHTMLタグです。見た目ではなく構造を読むための目印として、それぞれの意味を確認しましょう。

まず結論

5つのタグは、次のような感覚で読めれば十分です。

header  = 冒頭
nav     = 移動
main    = 主役
section = 章・まとまり
article = 独立した記事

これらは見た目ではなく「役割」を表すタグです。タグ名がそのまま、そのまとまりが何であるかを教えてくれます。

なぜ全部 div ではないのか

「divとspanの違い」で読んだとおり、divはひとまとまりを作る汎用的な「箱」で、特別な意味を持ちません。

例えば、次のように書いても動きます。

<div class="navigation">
  <a href="...">ホーム</a>
  <a href="...">カテゴリ</a>
</div>

でも、こう書けばどうでしょうか。

<nav>
  <a href="...">ホーム</a>
  <a href="...">カテゴリ</a>
</nav>

<nav>と書くだけで、「ここはナビゲーション」とコードを読む人にもブラウザにも伝わります。classの名前を読まなくても、タグ名だけで役割が分かるのです。

<header>・<nav>・<main>・<section>・<article>は、どれも「その部分がページの中で何の役割を持つか」を名前で示すタグです。

header とは？

headerは英語で「見出し」「冒頭部分」「ヘッダー」の意味です。Webでは、ページやまとまりの最初に置く導入部分として使います。

例えば次のものが入ることがあります。

  • サイト名
  • ロゴ
  • タグライン（紹介文）

このサイトでは、すべての記事ページの冒頭に実際に次のheaderがあります。

<header class="site-header compact">
  <div class="container">
    <div class="site-brand">
      <img class="site-logo" src="../assets/koi.png" alt="">
      <div class="site-brand-text">
        <a class="site-title" href="../index.html">コードは読めればいい。たぶん。</a>
        <p class="tagline">...</p>
      </div>
    </div>
  </div>
</header>

<header class="site-header compact">を見たら、「ここからサイトのヘッダーが始まる」と読めます。中にはロゴ画像・サイト名・紹介文が入っています。

英語から覚える：header

headerは英語で「頭・冒頭」を意味する言葉です。手紙や文書の「ヘッダー（最上部の記載）」と同じ感覚で、「ページの頭の部分」と覚えると読みやすくなります。

nav とは？

navはnavigation（ナビゲーション）の略です。navigationは英語で「案内」「移動」の意味で、船や飛行機の「航法」を表す言葉でもあります。

Webでは、他のページやページ内の場所へ移動するための主要なリンク群をまとめる部分に使います。例えば次のようなものが入ります。

  • カテゴリへのリンク
  • 学習ロードマップへのリンク
  • 新着記事・索引へのリンク

このサイトのトップページには、実際に次のnavがあります。

<nav aria-label="メインメニュー">
  <a class="nav-start" href="#start">はじめに</a>
  <a href="#categories">カテゴリ</a>
  <a href="#articles">学習ロードマップ</a>
  <a href="#latest">新着記事</a>
  <a href="indexes/index.html">索引</a>
  <a href="articles/about.html">このサイトについて</a>
</nav>

ただし、「リンクが1つあるだけで必ずnavにする」わけではありません。主要な移動リンクをまとめる場合に使うタグです。

main とは？

mainは英語の「主要な」「中心の」という意味です。Webでは、そのページの主役となる内容を囲うタグです。

初心者向けに言い換えると、「このページで一番読んでほしい部分」がmainの中に入ります。記事ページなら、例えば次のものが含まれます。

  • 記事タイトル（h1）
  • 本文
  • コード例

このサイトでは、記事の本文全体を囲うように<main class="article">が使われています。

<main class="article">
  <article class="container narrow">
    ...（記事の内容）...
  </article>
</main>

<main>を見たら、「ここからページの主な内容が始まる」と読みましょう。

section とは？

sectionは英語で「区分」「節」「章」の意味です。Webでは、内容上の意味のあるまとまりに使います。

目安として、見出しを持つひとまとまりの話題と考えると分かりやすくなります。

<section>
  <h2>headerとは？</h2>
  <p>...</p>
</section>

このサイトのトップページでは、「このサイトの目的」「カテゴリ」「学習ロードマップ」「新着記事」がそれぞれsectionで区切られています。

ただし、単に見た目を整えるためだけに囲いたい場合は、divの方が自然なこともあります。「意味のあるまとまり」かどうかが判断の目安です。

article とは？

articleは英語で「記事」の意味です。Webでは、それ単独でも意味が通る独立したコンテンツに使います。例えば次のようなものです。

  • ブログ記事
  • ニュース記事
  • 投稿・コメント

初心者向けの目安として、「その部分だけ切り取っても1つの読み物として成立するか？」を考えてみましょう。成立するならarticleが適切な候補になります。

このサイトの記事ページでは、本文全体を<article class="container narrow">で囲っています。記事ページの中身は、それ1本で独立した読み物として成立するからです。

section と article の違い

この2つは混乱しやすいポイントです。イメージとして、こう分けてみましょう。

  • article = 1本の記事そのもの
  • section = 1つの記事の中の章

例えば次のように入れ子にして読めます。

<article>
  <h1>APIとは？</h1>

  <section>
    <h2>まず結論</h2>
    <p>...</p>
  </section>

  <section>
    <h2>例えで理解する</h2>
    <p>...</p>
  </section>
</article>

外側のarticleが「APIとは？」という1本の記事を表し、内側のsectionが「まず結論」「例えで理解する」という章を表しています。

5つを並べて比べる

<header>

役割：冒頭・導入部分
読み方：ここからヘッダーが始まる

<nav>

役割：移動用のリンク群
読み方：ここはナビゲーション

<main>

役割：ページの主な内容
読み方：ここがページの中心

<section>

役割：意味のある話題のまとまり
読み方：ここから1つの章

<article>

役割：独立したコンテンツ
読み方：ここから1本の記事

このサイトの HTML を実際に読む

このサイトの記事ページの骨組みを、タグの役割を意識しながら読んでみましょう。

<header class="site-header compact">
  ...サイト名・ロゴなど...
</header>

<main class="article">
  <article class="container narrow">
    ...記事のタイトルと本文...
  </article>
</main>

<footer class="site-footer">
  ...著作権表示など...
</footer>

こう読めます。

  • <header class="site-header compact">：「サイトのヘッダーが始まる」
  • <main class="article">：「ここからページの主な内容」
  • <article class="container narrow">：「ここから1本の記事が始まる」
  • </article></main>：「記事と主な内容がここで終わる」

また、トップページには<nav aria-label="メインメニュー">や<section id="articles" class="section">などのタグも使われています。タグ名を見るだけで、そのまとまりの役割が一目で分かります。

見た目は CSS、意味は HTML

「HTML・CSS・JavaScriptの違い」で読んだとおり、見た目を担当するのはCSSです。

<header>や<main>を使ったからといって、特別なデザインになるわけではありません。例えばheaderを使っても、色や余白はすべてCSSで指定しています。

HTMLタグの役割は、「ここは何の部分なのか」という意味や構造を示すことです。見た目の指定はCSSが担当し、HTMLは「骨組みと役割」を書くものです。

semantic HTML について

header・nav・main・section・articleのように、意味を持つタグを使う考え方をsemantic HTML（セマンティックHTML）と呼ぶことがあります。

semanticは英語で「意味に関する」という意味です。意味のあるタグを使うと、人間にもブラウザにも構造が伝わりやすくなります。「ここはナビゲーション」「ここは記事」とタグ名だけで読めるコードは、divだけで書かれたコードより構造を追いやすくなります。

英語から覚える：semantic

semanticは「意味論的な」「意味に関する」という形容詞です。言語学では「言葉の意味を扱う分野」をsemantics（意味論）と呼びます。HTMLの文脈では「コードの意味・役割を大切にする」という方向性を指します。

よくある勘違い

  • 「headerはページに1個しか使えない」：必ずしもそうではありません。ページ全体のヘッダーだけでなく、記事や区画の冒頭部分に使うこともできます。ただし、初心者のうちはページの冒頭部分として読めれば十分です。
  • 「sectionは単なる装飾用の箱」：sectionは見た目を囲うためのタグではなく、内容上のまとまりを示すタグです。見た目だけ調整したいときはdivが適切です。
  • 「articleはブログ記事にしか使えない」：独立したコンテンツであれば、ブログ記事以外にも使えます。コメント欄の1件ひとつなど、単体で意味が通るものが目安です。

コードを読むときのコツ

HTMLを読むとき、タグを1行ずつ細かく追うより、まずページの大きな骨組みを見るのがコツです。

<header>    ← ここはヘッダー
  ...
</header>

<nav>       ← ここはナビゲーション
  ...
</nav>

<main>      ← ここからページの主な内容
  <article> ← ここから1本の記事
    <section> ← ここから1つの章
    </section>
  </article>
</main>

HTMLは入れ子になった箱として読むと分かりやすくなります。まず外側の大きなタグ（header・mainなど）を確認してページの全体像をつかみ、それから中身に入っていくと、構造が追いやすくなります。

今日覚えること

header＝冒頭、nav＝移動リンク、main＝ページの主役、section＝内容のまとまり、article＝独立したコンテンツ。

これらは見た目ではなく「役割」を表すタグです。divは意味の薄い汎用的な箱で、役割が明確な場合は専用のタグを使う方がHTMLの骨組みを読みやすくなります。
