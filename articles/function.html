トップ › functionとは？

functionとは？

functionは「処理のまとまり」。名前を付けて、必要なときに使えるようにしたものです。

AIが作ったコードに function と書いてあったら、 「ここでひとまとまりの作業を用意しているんだな」と考えてみてください。 日本語では「関数」と呼びます。まずは、処理のまとまり、引数、return、呼び出しの4つを押さえましょう。

1. functionは「処理のまとまり」

例えば「単価と数量から合計金額を計算する」という作業を、ひとまとめにできます。 このまとまりに名前を付けておけば、同じ計算の手順を何度も書かずに使えます。

function に続けて関数の名前を書き、 { と } の間に処理を書きます。 このように関数を用意することを「定義する」といいます。定義しただけでは、中の処理は実行されません。

英語から覚える：function

functionは英語で「機能・働き」を意味し、数学では「関数」を表します。「ひとつの働きを担当する処理のまとまり」と結び付けると、コードの役割を思い出しやすくなります。

GASの例：合計金額を計算する

Google Apps Script（GAS）は、JavaScriptで処理を書けるGoogleの仕組みです。 次の例では、200円の商品を3個買ったときの合計を計算し、実行ログに表示します。 実行ログは、処理の結果などを確認するための記録です。 

function calculateTotal(price, quantity) {
  return price * quantity;
}

function main() {
  const total = calculateTotal(200, 3);
  Logger.log(total);
}

これは、計算を担当する calculateTotal と、 その計算を使って結果を記録する main の2つを組み合わせた例です。 GASのエディタに貼り付けて保存し、実行する関数として main を選んで実行すると、 実行ログに 600 が表示されます。

2. 引数：処理に渡す材料

引数は「ひきすう」と読みます。関数に渡す値のことです。 この例の calculateTotal(200, 3) では、200 と 3 が引数です。

関数側では、丸かっこの中の price と quantity が受け取り口になります。 書いた順番に対応するので、price が200、quantity が3として扱われます。 * は掛け算の記号です。

渡す値を変えれば、同じ関数で別の金額も計算できます。 例えば calculateTotal(500, 2) なら結果は1000になります。 引数がいらない関数は、この例の main() のように丸かっこの中を空にできます。

3. return：結果を呼び出し元に返す

return は、その関数の処理をそこで終え、 結果を関数を使った場所へ返すためのものです。返した値を「戻り値」と呼びます。 この例では、return price * quantity; が計算結果の600を返します。

const total = calculateTotal(200, 3); は、 返ってきた結果に total という名前を付けて、後で使えるようにする行です。 ここでは total に600が入る、と考えれば大丈夫です。

return 自体は画面やログに結果を表示しません。 この例では、次の行の Logger.log(total) が結果をログに表示します。 値を返す必要がない関数では、main のように return を書かないこともあります。

4. functionを呼び出す：用意した処理を実行する

関数を「呼び出す」とは、その処理を実行するよう頼むことです。 コードでは、関数名の後ろに丸かっこを付けて calculateTotal(200, 3) のように書きます。 名前だけの calculateTotal では、計算は実行されません。

この例は、次の順番で進みます。

  1. GASで main を実行する。
  2. main の中から、200と3を渡して calculateTotal を呼び出す。
  3. calculateTotal が掛け算をして、return で600を返す。
  4. main に戻り、結果を total に入れて、ログに表示する。

AIが書いた関数を読むときは

まずは「何を受け取り、何をして、何を返すか」を探してみましょう。 分からなければ、AIに「この関数の引数、処理、戻り値、呼び出されている場所を説明してください」と頼めます。 細かい書き方をすべて覚えなくても、処理の流れを追う助けになります。

今日覚えること

functionは「処理のまとまり」。引数で材料を渡し、呼び出して実行し、returnで結果を受け取ります。
