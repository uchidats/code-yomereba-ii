. と () は何？ GASのコードを読むための基本

Google Apps Script（GAS）のコードを見ていると、SpreadsheetApp.getActiveSpreadsheet() のようにドット（.）とかっこ（()）がたくさん出てきます。それぞれの記号の役割が分かれば、長いコードも落ち着いて追えるようになります。

まず結論：. は「中身」、() は「実行」の合図

次のコードを見てみましょう。

SpreadsheetApp.getActiveSpreadsheet()

一見すると呪文のように長く見えますが、4つのパーツに分解できます。

  • SpreadsheetApp：Googleスプレッドシートを扱うための「道具箱」
  • .（ドット）：その道具箱の中にある機能を見る
  • getActiveSpreadsheet：呼び出したい機能の名前（今開いているスプレッドシートを取得する）
  • ()（かっこ）：その機能を実際に動かす（実行する）

「○○の中にある、△△という機能を、実行する！」と読むだけで、コードの骨組みがすっきり見えてきます。

.（ドット）は何？

. は、「左のものの中にある、右のもの」をつなぐ記号です。

SpreadsheetApp.getActiveSpreadsheet

これは、「SpreadsheetApp の中に入っている getActiveSpreadsheet という機能」を指しています。

日常の言葉で言えば、「の」に近い感覚です。

  • GmailApp.search → 「GmailApp の search（検索機能）」
  • CalendarApp.getDefaultCalendar → 「CalendarApp の getDefaultCalendar（標準カレンダー取得機能）」

コードの中で . を見かけたら、「左側の箱を開けて、右側の機能や情報を取り出しているんだな」と読みましょう。

()（かっこ）は何？

機能の名前の後ろに付いている () は、「その機能を実行する（呼び出す）」という合図です。

名前だけ書いた場合と、() を付けた場合では意味が違います。

getActiveSpreadsheet

機能の「名前」そのもの（まだ動かしていない）。

getActiveSpreadsheet()

() を付けて、「今すぐその機能を実行する！」と命令している。

テレビのリモコンに例えるなら、ボタンに書いてある「電源」という文字が機能名で、ボタンを実際に「ポチッと押す」動作が () です。

() の中に何か入る場合（引数）

() の中に、文字や数字が入っていることがあります。

GmailApp.search("from@example.com")

この "from@example.com" は、検索機能に渡している「材料（検索条件）」です。

英語から覚える：argument（引数：ひきすう）

プログラミングでは、関数や機能に渡す材料のことを「引数（ひきすう）」、英語で argument と呼びます。「関数に引っ張って渡す数や文字」というイメージです。

単に「メールを検索して！」と頼むだけでは、何を探せばいいか分かりません。そのため、() の中に "from@example.com" という材料を入れて、「このアドレスからのメールを探してね」と伝えています。

  • () が空っぽ：材料を渡さずに、そのまま実行する
  • ("...") に何か入っている：材料を渡して、それを使って実行する

GASでよく見る形

GASのコードでは、この「左 → . → 機能名 → ()」というパターンが何度も登場します。

SpreadsheetApp.getActiveSpreadsheet()
GmailApp.search("label:todo")
CalendarApp.getDefaultCalendar()
DriveApp.getFileById("abc123xyz")

どれも同じルールで分解できます。

  • SpreadsheetApp の中の getActiveSpreadsheet を () で実行
  • GmailApp の中の search に "label:todo" を渡して () で実行
  • CalendarApp の中の getDefaultCalendar を () で実行
  • DriveApp の中の getFileById にファイルのIDを渡して () で実行

それぞれの詳しい仕様を丸暗記する必要はありません。「左のサービスの、この機能を動かしているんだな」と構造を追えれば十分です。

連続する . はどう読む？

GASのコードを読んでいると、. が何個もつながっていることがあります。

SpreadsheetApp.getActiveSpreadsheet().getActiveSheet()

長く見えても慌てる必要はありません。左から順番に1つずつ追うだけです。

  1. まず SpreadsheetApp.getActiveSpreadsheet() で、今開いているスプレッドシート（ファイル全体）を受け取る
  2. その受け取ったファイルに対して .getActiveSheet() を実行し、現在開いているシート（1枚のタブ）を取得する

「ファイルを取得して、その中のシートを取得する」というように、前の結果に対して次の機能を続けて呼び出しています（専門用語では「メソッドチェーン」と呼ぶこともあります）。左から順番に読んでいけば自然に意味が分かります。

変数と組み合わせる

実際に動かすコードでは、取得した結果を変数に入れて取っておくことがよくあります。

const sheet = SpreadsheetApp.getActiveSpreadsheet();

このコードは次のように読みます。

  • SpreadsheetApp.getActiveSpreadsheet()：今開いているスプレッドシートを取得する
  • const sheet =：その取得結果に sheet という名前を付けて保存する

こうして一度変数に入れておけば、次の行からは sheet.getName() のように短い名前でそのスプレッドシートを操作できるようになります。

function（関数）とのつながり

「functionとは？」で学んだとおり、プログラミングでは処理のまとまりに名前を付けて「関数」と呼びます。

自分で関数を作るときも、Googleが用意してくれた機能を使うときも、「関数を呼び出すときは名前の後ろに () を付ける」というルールは共通です。

// 自分で作った関数を呼び出す
myFunction();

// Googleが用意した機能を呼び出す
Logger.log("こんにちは");

どちらも「名前 + ()」の形になっています。() はプログラムの世界共通の「動かして！」というスイッチです。

このサイトの実際のコードを読む

このサイトの「Google Apps Scriptとは？」という記事に、次の実在するコードが掲載されています。

function main() {
  const start = new Date("2027-01-15T10:00:00+09:00");
  const end = new Date("2027-01-15T10:30:00+09:00");
  CalendarApp.createEvent("GASの練習", start, end);
}

最後の行に注目してみましょう。

CalendarApp.createEvent("GASの練習", start, end);
  • CalendarApp：Googleカレンダーを操作する道具箱
  • .：その中にある機能を見る
  • createEvent：予定を作成する機能の名前
  • ("GASの練習", start, end)：予定の名前、開始時間、終了時間という3つの材料（引数）を渡して () で実行

記号の意味が分かると、何をしているコードなのかが自然と言葉で説明できるようになります。

コードを読むときの5つのステップ

. と () が入ったコードを見かけたら、次の順番で目を動かしてみましょう。

GmailApp.search("label:todo")
  1. 左側を見る：GmailApp（何を操作しようとしているか）
  2. . を見る：その道具箱の中身を開く
  3. 機能名を見る：search（どんな機能を使うか）
  4. () を見る：その機能を実行している合図
  5. () の中を見る："label:todo"（どんな材料を渡しているか）

このステップで分解すれば、どれほど長いコードが出てきても迷わずに意味を追うことができます。

今日覚えること
  • .（ドット） = 左側のものに属する機能や情報を見る（「〜の」の感覚）
  • ()（かっこ） = 関数・機能を実際に実行する合図
  • () の中には機能に渡す材料（引数 / argument）が入ることがある
  • GASでは SpreadsheetApp.xxx() のように「道具箱.機能()」の形が頻出する
  • . が続いていても、左から順番に分解すれば落ち着いて読める
