変数とは？ const・letを最低限だけ理解する

変数は「値に名前を付けて保存するもの」。まずは、名前と値の関係が分かれば大丈夫です。

AIが書いたコードには、const や let がよく出てきます。 どちらも変数を用意するための言葉です。 難しい決まりを全部覚える前に、「何に名前を付けているか」「後で値を入れ直すか」を見てみましょう。

変数：値に名前を付けて保存するもの

例えば、商品の単価が200円なら、const price = 200; と書けます。 これは「200という値に、priceという名前を付ける」という意味です。 後の処理では、price と書くことで、その値を使えます。

= は、ここでは「左右が等しい」という意味ではなく、 右側の値を左側の変数に入れる記号です。これを「代入」と呼びます。 初めて変数を用意することは「宣言」といいます。

数字だけでなく、const productName = "ノート"; のように文字も扱えます。 文字は引用符で囲みます。price（単価）や productName（商品名）のように、 中身が分かる名前だと、コードを読むときの助けになります。

ここでいう「保存」は、処理の中で後から使えるように覚えておくことです。 変数を作っただけで、スプレッドシートやファイルに記録されるわけではありません。

const：後から別の値を入れ直さない

const で用意した変数には、後から別の値を代入できません。 例えば const price = 200; の後に price = 300; と書いて実行すると、エラーになります。 同じ変数に値を入れ直すことを「再代入」といいます。

「この名前の値は途中で入れ替えない」と分かるので、処理を追いやすくなります。 const は、宣言するときに最初の値も指定します。

英語から覚える：const

constはconstant（一定の・変わらない）を短くした名前です。「一度決めた値を再代入で入れ替えない」と結び付けて覚えましょう。

let：後から値を入れ直せる

let は、途中で再代入する変数に使います。 例えば let quantity = 2; と書いた後に、 quantity = 3; と書けば、数量を2から3に変更できます。 入れ直すときは、let をもう一度書く必要はありません。

まずは基本的にconstを使い、後から値を変更する必要がある場合にletを使う、 という考え方で十分です。「変数」という名前でも、必ず値を変更するわけではありません。

なお、const が禁止するのは再代入です。 配列（値のリスト）やオブジェクト（名前付きのデータの集まり）では、中身を変更できる場合があります。 「constなら中身まで絶対に変わらない」とは限らないことだけ、覚えておきましょう。

英語から覚える：let

letは英語で「〜させる」を表し、数学の「Let x = 2」なら「xを2とする」という意味です。let quantity = 2; も「数量を2とする」と読むと理解しやすくなります。後から再代入できることは、JavaScriptのルールとして覚えましょう。

GASの例：数量を変えて合計金額を計算する

Google Apps Script（GAS）で、200円の商品を2個から3個に増やした場合の合計を計算してみます。 単価は入れ直さないので const、数量は途中で変えるので let を使います。 

function main() {
  const price = 200;
  let quantity = 2;

  quantity = quantity + 1;
  const total = price * quantity;

  Logger.log(total);
}

GASのエディタに貼り付けて保存し、実行する関数として main を選んで実行すると、 実行ログに 600 が表示されます。実行ログは、処理の結果などを確認するための記録です。

  1. price に単価の200、quantity に数量の2を入れます。
  2. quantity + 1 で今の数量に1を足し、結果の3を quantity に入れ直します。
  3. price * quantity で200と3を掛け、結果の600を total に入れます。
  4. Logger.log(total) で合計金額をログに表示します。

quantity = quantity + 1; は、右側の計算を先に行うと読むのがポイントです。 total は計算結果ですが、その後で値を入れ直さないので const にしています。 計算で決まる値にも const を使えます。

AIが書いた変数を読むときは

まずは「この名前には何が入るか」を確認し、let があれば「どこで値が変わるか」を探しましょう。 分からなければ、AIに「この変数に入る値と、const・letを使い分けている理由を説明してください」と頼めます。

今日覚えること

変数は「値に名前を付けて保存するもの」。基本はconst、後から値を入れ直す必要があるときはletを使います。
