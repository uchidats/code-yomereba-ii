SpreadsheetApp・GmailApp・CalendarAppとは？ GASのサービスを読む

GASのコードには SpreadsheetApp や GmailApp といった言葉がよく登場します。これらは、操作したいGoogleサービスごとに用意された「入口」です。入口を見れば、何のサービスを使おうとしているかがすぐに分かります。

「. と () は何？」という記事で、SpreadsheetApp.getActiveSpreadsheet() のようなコードを左から分解して読む方法を学びました。今回は、その先頭にある SpreadsheetApp や GmailApp などが何なのかを整理します。

まず結論：GASにはGoogleサービスごとに入口がある

GASには、操作したいGoogleサービスごとに、あらかじめ入口となる名前が用意されています。コードにその名前が出てきたら、「ここでそのサービスを使おうとしているんだな」と読むことができます。

代表的な入口は次の4つです。

SpreadsheetApp

Googleスプレッドシートへの入口

GmailApp

Gmailへの入口

CalendarApp

Googleカレンダーへの入口

DriveApp

Google Driveへの入口

名前に「App」が付いているものが多いことも、覚えておくと目印になります。GmailApp・CalendarApp・DriveApp・SpreadsheetApp のように、「サービス名 + App」という形になっています。

SpreadsheetApp：スプレッドシートへの入口

次のコードを見てみましょう。

const ss = SpreadsheetApp.getActiveSpreadsheet();

「. と () は何？」で学んだ読み方がそのまま使えます。

  • SpreadsheetApp：Googleスプレッドシートを扱うための入口（道具箱）
  • .：その入口の中にある機能を見る
  • getActiveSpreadsheet：現在開いているスプレッドシートを取得する機能
  • ()：その機能を実行する
  • const ss =：取得した結果を ss という名前で取っておく

前の記事で学んだ「左 → . → 機能名 → ()」の読み方が、ここでそのまま活きてきます。

GmailApp：Gmailへの入口

次のコードを見てみましょう。

const threads = GmailApp.search("label:todo");

GmailApp は、GASからGmailを操作するためのサービスです。

  • GmailApp：Gmailを扱うための入口
  • .：その入口の中にある機能を見る
  • search：メールを検索する機能
  • ("label:todo")：「label:todo」という検索条件を渡して実行

() の中には、「どんな条件で検索するか」という材料（引数）が入っています。ここでは「todoというラベルが付いたメール」を検索しています。GmailApp を見た時点で「Gmailに関する処理だな」と分かれば十分です。

CalendarApp：Googleカレンダーへの入口

次のコードを見てみましょう。

const calendar = CalendarApp.getDefaultCalendar();

CalendarApp は、GASからGoogleカレンダーを扱うための入口です。

  • CalendarApp：Googleカレンダーを扱うための入口
  • .：その入口の中にある機能を見る
  • getDefaultCalendar：自分の標準（デフォルト）のカレンダーを取得する機能
  • ()：その機能を実行する

CalendarApp と見えたら、「カレンダーの予定に関する処理」と即座に判断できます。

DriveApp：Google Driveへの入口

次のコードを見てみましょう。

const file = DriveApp.getFileById(fileId);

DriveApp は、Google Drive内のファイルやフォルダを扱うためのサービスです。

  • DriveApp：Google Driveを扱うための入口
  • .：その入口の中にある機能を見る
  • getFileById：IDを使ってファイルを取得する機能
  • (fileId)：取得したいファイルのIDを渡して実行

fileId という変数の中身がどこから来たかは、コード全体を追う必要がありますが、「DriveApp を使っているので、Driveのファイルを扱っているんだな」とだけ分かれば今は十分です。

「App」は全部同じ使い方？

完全に同じではありません。それぞれのサービスが持っている機能は異なりますし、取得できる情報も違います。

ただし、コードを読む上での基本的な形はどれも同じです。

○○App.機能()

この形を見たら、「○○というGoogleサービスに対して、何かの機能を呼び出している」と読む習慣を付けましょう。右側の機能名を全部覚えなくても、左端の ○○App さえ分かれば、何のサービスを操作しようとしているかは判断できます。

コードを読むときは左端を見る

GASのコードを見かけたとき、まず左端に注目してみましょう。

GmailApp.sendEmail(...)

GmailApp を見た瞬間に、「これはGmail関係の処理だ」と分かります。後ろの sendEmail は「メールを送信している」と読めますが、まず左端で大まかな処理の分野を把握することが重要です。

CalendarApp.createEvent(...)

CalendarApp と見えたら、「カレンダーに何かする処理」と分かります。createEvent は「予定を作成している」と推測できます。

長いコードを全部読む前に、左端を見るだけで「何のサービスを使っているか」が分かる——これは、GASのコードを読むときの大切なコツです。

読み方のポイント：左端を見る

SpreadsheetApp・GmailApp・CalendarApp・DriveApp のような名前を左端に発見したら、まず「どのGoogleサービスを操作しようとしているか」を判断しましょう。その後、. の右側で「何をしようとしているか」を確認すれば、コードの意図を大きくつかめます。

このサイトの実際のコードを読む

このサイトの「Google Apps Script（GAS）とは？」の記事には、次の実在するコードが掲載されています。

function main() {
  const start = new Date("2027-01-15T10:00:00+09:00");
  const end = new Date("2027-01-15T10:30:00+09:00");
  CalendarApp.createEvent("GASの練習", start, end);
}

最後の行に注目しましょう。

CalendarApp.createEvent("GASの練習", start, end);
  • 左端の CalendarApp：Googleカレンダーへの入口 → 「カレンダー関係の処理」と判断できる
  • .：その入口の中の機能を見る
  • createEvent：予定を作成する機能
  • ("GASの練習", start, end)：予定のタイトル、開始時刻、終了時刻を渡して実行

左端の CalendarApp を見た時点で「カレンダーに予定を追加するコードだ」と分かります。詳細は createEvent の部分で確認でき、自然に読み進められます。

また、「. と () は何？」の記事では、GmailApp.search("label:todo") というコードも例として使っています。GmailApp を見れば「Gmailで検索している」、search を見れば「検索機能を使っている」と読めます。

GASにはほかにもサービスがある

GASが用意しているサービスの入口は、ここで紹介した4つだけではありません。

  • DocumentApp：Google ドキュメントを操作するサービス
  • FormApp：Google フォームを操作するサービス
  • SlidesApp：Google スライドを操作するサービス

ただし、これらをすべて覚える必要はありません。コードを見かけたときに「○○App = ○○サービスへの入口」というパターンで調べれば十分です。このサイトの思想は「全部書けなくていい、読めれば十分」。知らない App が出てきたら、そのときに調べましょう。

コードを読むときの5つのステップ

GASのコードを読むときは、次の順番で目を動かしてみましょう。

const threads = GmailApp.search("label:todo");
  1. 左端の ○○App を見る：GmailApp → Gmailに関する処理だと判断する
  2. 何のGoogleサービスか判断する：Gmailを使っているので、メールに関係する処理
  3. . の右側を見る：search → 検索機能を使っている
  4. () で何を実行しているか読む：検索機能を呼び出している
  5. () の中を見る："label:todo" → 「todoラベルのメール」を検索条件として渡している

このステップで読めば、長いコードでも慌てず意味を追えます。前の記事で学んだ「. と () の読み方」と、この「左端 ○○App を見る」ことを組み合わせると、GASのコードの大半は読める構造になっています。

今日覚えること
  • SpreadsheetApp = Googleスプレッドシートへの入口
  • GmailApp = Gmailへの入口
  • CalendarApp = Googleカレンダーへの入口
  • DriveApp = Google Driveへの入口
  • ○○App.機能() の形を見たら「○○サービスで何かを実行している」と読む
  • まず左端の ○○App を見れば、何のサービスか判断できる
  • 全部暗記する必要はない。見かけたときに調べれば十分
