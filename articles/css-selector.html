CSSセレクタとは？ .class と #id を読む

CSSのコードを見たとき、.card や #start がHTMLのどの部分を指しているかが分かれば、デザインがどのように適用されているかをスムーズに追えるようになります。

まず結論：. は class、# は id を探す目印

次のCSSを見てください。

.card {
  padding: 16px;
}

先頭に .（ドット）が付いた .card は、「class="card" が付いている要素を探して、その見た目を指定する」と読みます。

一方、先頭に #（シャープ／ハッシュ）が付いている場合はどうでしょうか。

#start {
  margin-top: 20px;
}

#start は、「id="start" が付いている要素を対象にしている」と読みます。

  • . を見たら → class を探す
  • # を見たら → id を探す

これさえ知っておけば、CSSの先頭に書いてある言葉の役割がひと目で分かります。

そもそも「セレクタ」とは？

英語から覚える：selector（セレクタ）

selector は英語で「選ぶもの」「選択するもの」という意味です。家電のチャンネル切り替えスイッチ（セレクター）と同じ言葉です。

CSSでは、どのHTML要素にスタイルを適用するかを選ぶ部分を「セレクタ」と呼びます。

.card {
  padding: 16px;
}
  • .card：セレクタ（対象を選ぶ）
  • { } の中身：適用する見た目の指定（余白を16pxにする）

「セレクタで対象を選び、波かっこ { } の中で見た目を指定する」というのが、CSSの基本構造です。

.class の意味：classセレクタ

「classとidの違い」で見たように、HTMLではグループ名として class を付けます。

HTML側：

<div class="card">
  <p>お知らせ</p>
</div>

CSS側：

.card {
  border-radius: 12px;
}

CSSでは、classの値の前に . を付けて指定します。つまり、

class="card" ↕ .card

という対応関係になっています。CSSで .card を見かけたら、HTML側にある class="card" を探せば、どこにスタイルが当たるかが分かります。

#id の意味：idセレクタ

同じくHTMLで特定の要素に付ける固有名が id です。

HTML側：

<section id="start">
  <h2>このサイトの目的</h2>
</section>

CSS側：

#start {
  scroll-margin-top: 80px;
}

CSSでは、idの値の前に # を付けて指定します。つまり、

id="start" ↕ #start

という対応関係です。CSSで #start を見かけたら、HTML側にある id="start" を探します。

. と # の違い

覚えるルールはとてもシンプルです。

  • . = class（複数の要素で共有できるグループ名）
  • # = id（ページ内で重複させない1つだけの固有名）

Webサイトでは同じ見た目を使い回すことが多いため、実際のCSSでは # よりも .（classセレクタ）を見かける場面が圧倒的に多くなります。

タグ名そのものをセレクタにすることもある（要素セレクタ）

. や # を付けず、タグ名をそのままセレクタとして書くこともあります。

p {
  line-height: 1.8;
}

これは「ページ内にあるすべての <p> タグ（段落）の行間を1.8にする」という指定です。

まずは次の3種類が分かれば十分です。

.card（classセレクタ）

class="card" を持つ要素をすべて対象にする。

#start（idセレクタ）

id="start" を持つ固有の要素を対象にする。

p（要素セレクタ）

すべての <p> タグをまとめて対象にする。

このサイトの実際のCSSを読む

このサイトで実際に使われている assets/styles.css から、いくつかセレクタを見てみましょう。

.site-header {
  border-bottom: 1px solid var(--line);
  background: var(--surface);
}

.site-logo {
  display: block;
  width: 44px;
  height: auto;
}

.tagline {
  margin: 4px 0 0;
  font-size: 0.85rem;
  color: var(--muted);
}

これらはすべて . から始まっているため、classを指定していることが分かります。

  • .site-header → HTMLの class="site-header"（ヘッダー全体）
  • .site-logo → HTMLの class="site-logo"（鯉のロゴ画像）
  • .tagline → HTMLの class="tagline"（サイトの説明文）

「CSSのセレクタを見たら、HTML側で同じclass名を探す」という読み方をすれば、どのデザインがどの要素に当たっているかがすぐに分かります。

CSSを読むときはHTMLと行き来する

コードを読むときに最も大切なのは、HTMLとCSSのあいだを行き来する視点です。

CSSからHTMLを探すとき

CSSで .site-logo { width: 44px; } を見たら、HTMLで class="site-logo" を探す。

HTMLからCSSを探すとき

HTMLで <div class="card"> を見たら、CSSで .card の記述を探す。

HTMLの構造とCSSの見た目は、class名やid名という「共通の名前」でつながっています。この往復ができるようになると、Webページのコードがぐっと身近に感じられるはずです。

{ } の中は何？

波かっこ { } の中には、具体的な見た目のルールが書かれています。

.card {
  padding: 16px;
  border-radius: 12px;
}
  • .card：対象を選ぶ（カードの要素）
  • { ... }：その対象に対する見た目の指定（内側の余白や角の丸みなど）

padding や border-radius などのプロパティの詳しい意味は、必要になったときに調べれば大丈夫です。「セレクタが選んだ相手に対して、波かっこの中身が適用される」という関係だけを押さえておきましょう。

よく見るセレクタの対応表

.name

HTML：class="name"
同じグループの要素をまとめて指定する。

#name

HTML：id="name"
ページ内で特定の1つだけを指定する。

p

HTML：<p>
そのタグ名を持つ要素全体を指定する。

CSSを読むときのステップ

CSSのコードを見かけたら、次の順番で視点を動かしてみましょう。

  1. セレクタを見る：先頭の文字を確認する
  2. . なら class、# なら id と判断する
  3. HTML側で同じ名前を探す：どの要素が選ばれているかを確認する
  4. { } の中身を見る：どんな見た目が指定されているかを読む

全部を暗記する必要はありません。セレクタの先頭の記号を手がかりに、HTMLとつなげて読んでみてください。

今日覚えること
  • セレクタ = CSSでスタイルを適用する対象を選ぶ部分
  • .card は class="card" を持つ要素を指定する（. は class）
  • #start は id="start" を持つ要素を指定する（# は id）
  • p のようにタグ名そのものを指定する要素セレクタもある
  • CSSを読むときは、HTML側の class や id と対応させて行き来する
