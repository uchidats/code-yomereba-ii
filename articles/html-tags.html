HTMLタグとは？ < > の中には何が書いてある？

HTMLのコードを見たとき、<div>や<a href="...">の山かっこの中に何が書いてあるか分かれば、コードの構造がぐっと読みやすくなります。

まず結論：HTMLタグは「ここから○○」「ここまで○○」の目印

次のコードを見てください。

<p>こんにちは</p>
  • <p>：ここから段落が始まる
  • こんにちは：中身（テキスト）
  • </p>：ここで段落が終わる

HTMLタグは「ここから○○」「ここまで○○」という目印です。この読み方さえ分かれば、HTMLのコードを見たとき、構造を追えるようになります。

そもそも「タグ」とは？

英語から覚える：tag

tagは英語で「札」「ラベル」「荷札」などの意味です。荷物に付ける値札や、商品のタグをイメージすると分かりやすくなります。

HTMLでは、文章や画像などに「これは見出し」「これは段落」「これはリンク」と札を付けるようなイメージで使います。

<h1>タイトル</h1>
<p>本文です。</p>
  • h1：見出し（heading 1の略）
  • p：段落

タグ名を見るだけで「このまとまりが何者か」が伝わります。英語の意味が分かると、タグは暗号ではなくなります。

< > は何？

<と>で囲まれた部分がHTMLタグです。この記号は「山かっこ（angle bracket）」と呼ばれます。

<p>

山かっこの中の p がタグ名です。山かっこの中を見ると「この部分が何者か」が分かる、と読みましょう。

英語から覚える：p = paragraph

pはparagraph（段落）の略です。paragraph＝段落、と結び付けると、なぜ段落に<p>を使うのかが覚えやすくなります。

開始タグと終了タグ

多くのHTMLタグには「開始タグ」と「終了タグ」があります。

<p>本文です。</p>
  • <p>：開始タグ
  • </p>：終了タグ

終了タグでは、タグ名の前に/（スラッシュ）が付くのがポイントです。「/ が付いたら、ここで終わり」と読めば大丈夫です。

<tag>（始まり）

開始タグ。ここからその要素が始まる目印です。

</tag>（終わり）

終了タグ。/ が付いたら「ここで終わり」と読みます。

タグの中身

開始タグと終了タグに挟まれた部分が「内容」です。

<p>これは本文です。</p>

「これは本文です。」がこの<p>タグの内容です。HTMLでは、

開始タグ → 内容 → 終了タグ

という形がよく出てきます。内容にはテキストだけでなく、別のタグが入ることもあります。

タグは入れ子になる

HTMLでは、タグの中に別のタグを入れることができます。

<div>
  <p>本文です。</p>
</div>

divの中にpが入っています。さらに、複数のタグが入ることもあります。

<div class="card">
  <h2>タイトル</h2>
  <p>説明文です。</p>
</div>

HTMLは箱の中に箱が入っているような構造です。大きな箱（div）の中に、見出し（h2）と段落（p）という小さな箱が入っています。

英語から覚える：nesting（入れ子）

nestingは英語で「入れ子」の意味です。nestは「鳥の巣」や「組み合わさって収まる形」を意味し、小さいものが大きいものの中に収まるイメージと結び付けると覚えやすくなります。

この「箱の中に箱」という構造は、「divとspanの違い」や「header・nav・main・section・articleの違い」でも詳しく見てきました。タグが入れ子になっているとき、どこからどこまでが1つのまとまりかを意識するとコードが読みやすくなります。

属性とは？

タグには、追加の情報を書くことができます。

<a href="../index.html">トップへ戻る</a>
  • a：タグ名（リンクを表す）
  • href="../index.html"：追加情報（どこへ移動するか）

このような追加情報を属性（attribute）と呼びます。

英語から覚える：attribute（属性）

attributeは「属性」「特徴」という意味の英単語です。「そのタグが持っている特徴・追加情報」と結び付けると覚えやすくなります。

属性は「タグに追加の情報を与えるもの」と理解すれば十分です。細かな種類は、使いながら覚えていけます。

class と id も属性

以前の記事でも出てきた class や id も、属性の一種です。

<div class="card">
<section id="start">
  • class="card"：このまとまりに「card」というグループ名を付ける属性
  • id="start"：このsectionに「start」という固有名を付ける属性

詳しくは「classとidの違い」で読めますが、どちらも「そのタグに追加の名前情報を与える属性」と読めます。

href と src も属性

リンクや画像でよく見る href と src も属性です。

<a href="../index.html">トップへ戻る</a>
<img src="../assets/koi.png" alt="">
  • href="../index.html"：移動先のファイルを指定する属性
  • src="../assets/koi.png"：表示する画像ファイルの場所を指定する属性

hrefとsrcの役割の違いは「hrefとsrcの違い」で詳しく説明しています。どちらも属性の一種であり、タグに追加情報を与えている、と読めれば大丈夫です。

閉じタグがないように見えるものもある

HTMLには、終了タグを書かない要素もあります。

<img src="../assets/koi.png" alt="">
<meta charset="utf-8">

</img>や</meta>を書かなくても動きます。これらは「内容を挟む」ではなく、「それ自体が1つの指示」として機能するためです。

専門的にはvoid element（空要素）と呼びます。「すべてのタグに終了タグがあるわけではない」と覚えれば十分です。

a の a は何の略？

よく見るタグの名前には、英語の由来があります。由来が分かると、タグは暗号ではなくなります。

p = paragraph（段落）

文章の段落を表します。

a = anchor（錨）

リンクを作るタグ。anchorは「錨」の意味で、リンク先に「つなぎとめる」イメージです。

img = image（画像）

画像を表示するタグです。

nav = navigation（案内）

移動用のリンクをまとめるタグです。

main = main（主要）

ページの主な内容を囲うタグです。

article = article（記事）

独立したひとまとまりの内容を表すタグです。

このサイトのコードを実際に読む

このサイトの記事ページのヘッダーには、次の開始タグがあります。

<header class="site-header compact">
  • header：タグ名（ページのヘッダー部分を表す）
  • class：属性の名前
  • "site-header compact"：classの値（空白で区切って2つのclassを持っている）

さらに、同じヘッダーの中には次のようなコードもあります。

<img class="site-logo" src="../assets/koi.png" alt="" width="1148" height="1371">
  • img：画像タグ（image の略）
  • class="site-logo"：見た目やグループ分けに使う属性
  • src="../assets/koi.png"：画像ファイルの場所を指定する属性
  • alt=""：画像の代替テキスト（ここでは空）を指定する属性
  • width・height：画像の幅と高さを指定する属性

1つの開始タグの中に、複数の属性が並ぶこともあります。それぞれが「このタグへの追加情報」と読めます。

HTMLを読むときのコツ

HTMLを1文字ずつ読もうとすると、どこから手を付ければいいか分からなくなります。次の順番で読むと、全体の構造がつかみやすくなります。

  1. タグ名を見る：何の要素か確認する
  2. 属性を見る：追加の情報（名前・場所・リンク先など）を確認する
  3. どこまで囲っているかを見る：終了タグを探し、内容の範囲を把握する

例えば、このサイトのトップページには次のようなリンクがあります。

<a class="nav-start" href="#start">はじめに</a>

この順番で読んでみましょう。

  • aタグ → リンクを表す
  • class="nav-start" → nav-startというグループ名が付いている
  • href="#start" → ページ内のidがstartの場所への移動先
  • 挟まれているのは「はじめに」というテキスト

「aタグなのでリンク。classはnav-start。hrefはstartという場所への移動先。表示される文字は『はじめに』」と読めます。

最初はゆっくりで大丈夫です。タグ名→属性→範囲の順に読む習慣を付けると、知らないタグでも構造を追えるようになります。

今日覚えること
  • HTMLタグ = 要素の役割を示す札（< >の中にタグ名を書く）
  • <tag> = 開始、</tag> = 終了（/ が付けば終了タグ）
  • タグの中に別のタグを入れることができる（入れ子構造）
  • class・id・href・srcなどはすべて「属性」= タグへの追加情報
  • すべてのタグに終了タグがあるわけではない（<img>・<meta>など）
