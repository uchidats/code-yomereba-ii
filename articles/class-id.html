classとidの違い｜HTMLの「グループ名」と「固有名」

classは複数の要素で共有できる「グループ名」、idはページ内の特定の1か所を指す「固有名」です。HTMLの名前とCSSの記号をつなげて、どの部分を指定しているか読んでみましょう。

まず結論：グループ名と、特定の場所の名前

次は説明用のHTMLです。2つの段落には、同じnoteというclassが付いています。

<p class="note">注意1</p>
<p class="note">注意2</p>

どちらも「noteグループの段落」と読めます。一方、次の開始タグは「このページのstartという特定の場所」です。

<section id="start">

classは同じ種類の名札、idは個人番号、くらいのイメージです。名前が付いたことで、CSSやリンクからその要素を指定しやすくなります。

classは同じ特徴の要素をまとめる名前

英語から覚える：class

classには「分類」「種類」「クラス」という意味があります。HTMLでは、同じ特徴を持つ要素をまとめて扱うための名前、と考えると分かりやすくなります。

先ほどの2つの段落を太字にしたいとき、CSSでは次のように指定できます。これは説明用のCSSで、このサイトにある設定そのものではありません。

.note {
  font-weight: bold;
}

.noteは「noteというclassを持つ要素」、font-weight: bold;は「文字を太くする」です。このCSSが適用されると、2つの段落が両方とも太字になります。

同じclass名は、複数の要素に付けられます。HTMLにはclass="note"、CSSには.noteと書かれていたら、同じグループを指しています。

idはページ内の1か所を識別する名前

英語から覚える：id = identifier

idはidentifierの略です。identifierは「識別子」、つまり「見分けるための名前」という意味で、ページ内の特定の要素を識別します。

<section id="start">なら、そのsectionにstartという固有名を付けています。同じページ内では、同じidの値を重複させず、1つの要素だけに使います。

CSSから指定するときは、名前の前に#を付けます。次は読み方のための例で、実際のサイトにある設定ではありません。

#start {
  background: #fff8e3;
}

先頭の#startは「idがstartの要素」です。この例はその背景色を指定しています。なお、#fff8e3は色の値なので、同じ#でも書かれた場所によって意味が違います。

classとidを並べて比べる

class：グループ名

役割：同じ種類の要素をまとめる
共有：同じ名前を複数の要素で使える
HTML：class="name"
CSS：.name

id：固有名

役割：特定の1要素を識別する
共有：同じ名前は同じページ内で1回
HTML：id="name"
CSS：#name

別のHTMLページなら、同じid名を使えます。「このページの中で1つ」と読むのがポイントです。

このサイトのclassを読んでみる

記事ページのヘッダーには、実際に次の開始タグがあります。

<header class="site-header compact">

これは「site-header compact」という1つの名前ではありません。空白で区切られた、次の2つのclassを持っています。

  • site-header：サイトのヘッダーに付けるclass。
  • compact：このサイトでは、ヘッダーの余白を調整するためにも使うclass。

1つの要素に複数のclassを付けられます。どんな見た目になるかは、名前だけで決まるのではなく、対応するCSSを見て確認します。

ほかにも、ヘッダーには次のclassが使われています。ここでは属性の部分だけを抜き出しています。

class="site-title"
class="tagline"
class="site-logo"

このサイトでは順に、サイト名のリンク、紹介文、錦鯉のロゴ画像に付いています。CSSの.site-titleを見つけたら、「サイト名のリンクの見た目を指定しているんだな」とつなげて読めます。

このサイトのidと、ページ内リンク

トップページには、次のリンクとsectionがあります。sectionの中身は省略しています。

<a class="nav-start" href="#start">はじめに</a>

<section id="start" class="section">

href="#start"は「このページ内の、idがstartの場所へ移動する」という意味です。クリックすると、サイトの目的が書かれたsectionへ移動します。このサイトでは「はじめに」のナビゲーションリンクはPC表示で確認できます。

「hrefとsrcの違い」で見たhrefの行き先は、別ファイルだけとは限りません。#startのように、同じページの特定の場所も指定できます。

記事ページからなら../index.html#startと読むこともできます。相対パスの道順でトップページへ行き、その中のstartへ進む、という組み合わせです。トップページの「このサイトの目的」へというリンクでも確認できます。

このsectionはid="start"とclass="section"の両方を持っています。グループ名と固有名は、1つの要素に一緒に付けられます。

なぜclassは共有できて、idは1つなのか

classは、同じ種類をまとめて扱うためのものです。同じグループにいくつも要素が入っていて自然です。

idは、特定の場所を一意に見つけるためのものです。同じページにstartが何個もあると、「どのstartへ行けばいいのか」が曖昧になります。見た目が表示できていても、同じid名を重複して付けるのは避けます。

CSSでは「.はclass、#はid」

CSSで要素を選ぶ部分を読むときは、まず名前の前の記号に注目します。

.site-title  → classがsite-titleの要素
#start       → idがstartの要素

.はclass、#はid。HTML側の値には、この記号を付けません。class="site-title"と.site-title、id="start"と#startを対にして読むと分かりやすくなります。

JavaScriptでも、要素を探す名前になる

classやidは、JavaScriptからページ内の要素を探すときにも使われます。次は説明用の例です。

document.getElementById('start')

「このページから、idがstartの要素を探して取得する」と読みます。これだけで、その場所へ移動するわけではありません。今回は、idはJavaScriptにとっても探す目印になる、と分かれば十分です。

よくある勘違いは、この3つ

  • 「classは1つしか付けられない」：空白で区切れば複数付けられます。site-header compactは2つのclassです。
  • 「idも同じ名前を何度でも使える」：同じページ内では重複させません。共有するグループ名にはclassを使います。
  • 「HTMLにも.や#を付ける」：名前を付けるHTMLではclass="note"やid="start"です。CSSで選ぶときに.noteや#startになります。

コードを読むときは、名前の役割を言葉にする

<div class="card">
<section id="start">

それぞれの開始タグを、「このdivはcardというグループに属する」「このsectionはstartという固有名を持つ」と読んでみましょう。

次にCSSの.cardや、リンクのhref="#start"を見つければ、どこにつながる指定かが分かります。全部を書けなくても、名前をたどることでコードの意味を追えます。

今日覚えること

classは共有できるグループ名、idは同じページ内で重複させない固有名で、CSSでは.class名と#id名で指定します。

1つの要素には、空白で区切って複数のclassを付けられます。
