const

再代入しない変数の宣言。「この名前で値を扱い、別の値は入れ直さない」と読みます。配列やオブジェクトの中身まで変更禁止になるわけではありません。

関連記事：変数とは？

let

再代入できる変数の宣言。「この名前の値は後で変わるかもしれない」と読み、値を入れ直す箇所を探します。

関連記事：変数とは？

if

条件による分かれ道。「もし丸かっこの条件が成り立つなら、この処理をする」と読みます。

関連記事：if文とは？

else

条件に合わなかった場合の処理。「それ以外なら、こちらを実行する」と読みます。

関連記事：if文とは？

function

関数を定義する目印。「ここから呼び出せる処理のまとまりを用意する」と読みます。

関連記事：functionとは？

return

関数を終え、結果を呼び出し元へ返す目印。「この値を戻して、ここで関数を終える」と読みます。値を書かないreturnもあります。

関連記事：functionとは？

true

真を表す値。「条件が成り立つ」「はい」に当たる値として読みます。引用符付きの文字列とは別です。

関連記事：JSONとは？

false

偽を表す値。「条件が成り立たない」「いいえ」に当たる値として読みます。

関連記事：JSONとは？

null

値がないことを明示する値。「ここには値を入れていない」と読みます。0や空の文字列とは別です。

関連記事：JSONとは？

undefined

値がまだ設定されていないことなどを表す値。存在しない項目を読んだときや、値を返さない関数の結果にも現れます。

関連記事：JSONとは？

=

値を代入する記号。「右の値を左の名前に入れる」と読みます。等しいかを調べる比較とは異なります。

関連記事：変数とは？

==

型の変換を伴うことがある比較。「同じとみなせるか？」と読み、例えば数値の1と文字列の"1"も同じと判定します。

関連記事：if文とは？

===

型を変換しない比較。「値と型が同じか？」と読みます。オブジェクトや配列では、中身の一致ではなく同じものを参照しているかを比べます。

関連記事：if文とは？

!=

型の変換を伴うことがある不一致の比較。「==で同じとみなされないか？」と読みます。

関連記事：if文とは？

!==

型を変換しない不一致の比較。「===で同じと判定されないか？」と読みます。数値の1と文字列の"1"は異なると判定します。

関連記事：if文とは？

&&

条件をつなぐ「かつ」。条件式では「両方とも成り立つか」と読みます。実際には左側の値に応じて、どちらかの値を返します。

関連記事：if文とは？

||

条件をつなぐ「または」。条件式では「どちらかが成り立つか」と読みます。実際には左側の値に応じて、どちらかの値を返します。

関連記事：if文とは？

!

真偽を反転する記号。「〜ではない」と読み、例えば!trueはfalseになります。

関連記事：if文とは？

=>

アロー関数の目印。「左側で情報を受け取り、右側で処理する関数」と読みます。大小を比べる記号ではありません。

関連記事：functionとは？

()

関数の引数や条件、計算のまとまりを囲む丸かっこ。名前の直後なら「関数を呼ぶ」、ifの直後なら「条件を調べる」と周囲から読み分けます。

関連記事：. と () は何？、functionとは？

[]

配列や要素の参照に使う角かっこ。「値の一覧」や「一覧の何番目かを読む」と読みます。JavaScriptの配列の番号は0から始まります。

関連記事：JSONとは？

{}

処理やデータをまとめる波かっこ。ifや関数の後ろなら処理の範囲、JSONなら名前と値をまとめたオブジェクトと読みます。

関連記事：JSONとは？

.

中の項目や機能を参照する記号。GmailAppの後ろなら「GmailAppが持つ機能」と読みます。CSSでは.class名のようにクラスの指定にも使います。

関連記事：. と () は何？、Google Apps Script（GAS）とは？、classとidの違い（CSSの.）

:

名前と値を対応させる区切り。JSONの"name": "Masa"なら「nameの値はMasa」、CSSのcolor: blueなら「文字色は青」と読みます。

関連記事：JSONとは？

,

項目の区切り。配列の値、オブジェクトの項目、関数に渡す引数などを分けて読みます。

関連記事：JSONとは？

;

文や指定の区切り。JavaScriptでは「ここで1つの文が終わる」、CSSでは「ここで1つの指定が終わる」と読みます。

関連記事：HTML・CSS・JavaScriptの違い

>=

「以上」の比較。score >= 80なら「点数が80以上か」と読み、80ちょうども含めます。

関連記事：if文とは？

+

数値の足し算や文字列の連結。前後の値を見て「足す」か「文字をつなぐ」かを読み分けます。

関連記事：変数とは？

*

掛け算。price * quantityなら「単価と数量を掛ける」と読みます。

関連記事：変数とは？

JSON.stringify()

JavaScriptの値をJSONの文字列へ変換する関数。「データを送信・保存用の文字にする」と読みます。undefinedなど、JSONにそのまま表せない値もあります。

<div>

複数の要素などを囲う汎用的なまとまり。「ここからひとかたまりが始まる」と読みます。標準ではブロック表示ですが、CSSで表示方法を変えられます。

関連記事：divとspanの違い

<span>

文章などの一部分を囲う汎用的な要素。「この範囲だけを指定する目印」と読みます。標準ではインライン表示で、classを付けて一部分だけの表示などを指定できます。

関連記事：divとspanの違い

<a>

リンクを表すHTML要素。hrefがあれば「ここを押すと指定先へ移動する」と読みます。

関連記事：HTML・CSS・JavaScriptの違い

<img>

画像を表示するHTML要素。「srcの場所にある画像を表示する」と読みます。

関連記事：HTML・CSS・JavaScriptの違い

class

共有できるグループ名。同じ名前を複数の要素に付けられ、空白で区切れば1つの要素に複数のclassを付けられます。CSSでは.名前と読みます。

関連記事：classとidの違い

id

ページ内の特定の要素を指す固有名。同じページ内で値を重複させず、CSSでは#名前、ページ内リンクではhref="#名前"で指定します。

関連記事：classとidの違い

href

参照先を表す属性。a要素なら「クリックしたときの移動先」、link要素なら「CSSなどの参照先」と読みます。Hypertext Referenceのreferenceは「参照」という意味です。

関連記事：hrefとsrcの違い

src

読み込み元を表す属性。img要素なら画像、script要素ならJavaScriptファイルの場所を指定します。source（元・出どころ）の略と結び付けて読みます。

関連記事：hrefとsrcの違い

../

1つ上のフォルダへ戻る道順。../assets/koi.pngなら「1つ上へ戻り、assetsの中のkoi.pngを探す」と読みます。必ずトップページへ戻る意味ではありません。

関連記事：相対パスとは？

../../

2つ上のフォルダへ戻る道順。「上へ戻る」を2回続ける、と読みます。

関連記事：相対パスとは？

./

今いるフォルダを表す指定。HTMLの ./photo.png は、同じフォルダのphoto.pngを指し、この例では ./ を省略しても同じ場所になります。

関連記事：相対パスとは？

#（CSSのid指定）

CSSで要素を選ぶとき、#startは「idがstartの要素」と読みます。href="#start"ではページ内の移動先を示しますが、#fff8e3のような色の値は別の意味です。

関連記事：CSSセレクタとは？、classとidの違い

<header>

ページや区画の冒頭部分を表すHTML要素。「ここからヘッダーが始まる」と読みます。サイト名・ロゴ・タグラインなどが入ることがあります。

関連記事：header・nav・main・section・articleの違い

<nav>

navigationの略で、移動用のリンク群をまとめるHTML要素。「ここはナビゲーション」と読みます。主要なリンクをまとめる場合に使います。

関連記事：header・nav・main・section・articleの違い

<main>

そのページの主な内容を囲うHTML要素。「ここからページの中心となる内容」と読みます。記事ページであれば記事タイトルや本文が中に入ります。

関連記事：header・nav・main・section・articleの違い

<section>

内容上の意味のあるまとまりを表すHTML要素。「ここから1つの章・話題が始まる」と読みます。見出しを持つひとまとまりの話題が目安です。

関連記事：header・nav・main・section・articleの違い

<article>

それ単独でも意味が通る独立したコンテンツを表すHTML要素。「ここから1本の記事が始まる」と読みます。「切り取っても読み物として成立するか」が目安です。

関連記事：header・nav・main・section・articleの違い

<tag>（開始タグ）

HTMLの開始タグの形。<と>の中にタグ名を書く。「ここからこの要素が始まる」と読みます。

関連記事：HTMLタグとは？

</tag>（終了タグ）

HTMLの終了タグの形。タグ名の前に/が付く。「/ が付いたらここで終わり」と読みます。

関連記事：HTMLタグとは？

<p>

段落（paragraph）を表すHTML要素。「ここからひとつの段落が始まる」と読みます。pはparagraphの略です。

関連記事：HTMLタグとは？

alt

画像の代替テキストを指定する属性。画像が読み込めないときや読み上げ時に使われます。alternative（代わりの）の略です。

関連記事：属性とは？、hrefとsrcの違い

.class

CSSでclassを指定するセレクタ。.card なら「class="card" を持つ要素」と読みます。

関連記事：CSSセレクタとは？、classとidの違い

#id

CSSでidを指定するセレクタ。#start なら「id="start" を持つ特定の要素」と読みます。

関連記事：CSSセレクタとは？、classとidの違い

要素名 { }

CSSでHTMLタグ名を直接セレクタにする書き方（要素セレクタ）。p { } なら「すべてのp要素」と読みます。

関連記事：CSSセレクタとは？

Gitのコマンド

  • git commit --amend
  • git push --force-with-lease
git commit --amend

直前のcommitを作り直すコマンド。「最後の記録を修正する」と読みますが、別のcommitになるため、送信済みなら接続先との履歴の違いに注意します。

関連記事：1日でこのサイトを公開するまで

git push --force-with-lease

接続先の履歴が想定した状態かを確認して、履歴の強制更新を試みる指定。「相手側が想定どおりなら、作り直した履歴を送る」と読みます。通常のpushとは異なり履歴を書き換えるため、同期の問題すべてに使うコマンドではありません。
