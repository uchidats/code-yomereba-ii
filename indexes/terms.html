AI（エーアイ）

Artificial Intelligence（人工知能）の略。文章やコードの説明・作成などを支援する技術です。

GoogleのAI開発環境（エージェント支援ツール）。プロジェクトのファイルを直接読み込み、編集や確認などの作業を支援します。

Integrated Development Environment（統合開発環境）の略。コードの編集、ファイル管理、ターミナル実行などをまとめて行えるソフトウェアです。

関連記事：CodexのバックアップとしてAntigravityを試してみた

model / モデル

VS Code（ブイエスコード）

エージェント

指示に沿って調査や編集、確認などの作業を進めるAI。コードについて相談するだけでなく、作業も任せる場面で出てきます。

absolute path / 絶対パス

最上位の場所から指定する道順。Webでは / から始まるパスはドメイン直下を基準にし、完全なURLなら接続先も含めて指定します。

関連記事：相対パスとは？

backend / バックエンド

サービスの裏側で、データの保存や処理などを担当する部分。「裏側の担当」と読むと役割をつかめます。

関連記事：APIとは？

block / ブロック

通常のレイアウトでは新しい行から始まり、親の横幅を使う表示。divの標準の表示がこれに当たりますが、CSSで変更できます。

関連記事：divとspanの違い

breadcrumb / パンくず

「トップ › 索引 › 用語索引」のように、サイト内の現在位置を示すリンクの並び。breadcrumbは英語で「パンくず」を意味します。

関連記事：HTML・CSS・JavaScriptの違い

class / クラス

英語で「分類・種類」の意味。HTMLでは同じ特徴の要素をまとめるグループ名で、同じ名前を複数の要素に付けられます。

関連記事：classとidの違い

CSS（シーエスエス）

Cascading Style Sheetsの略。文字の色・大きさ・余白など、ページの見た目を指定するものです。

関連記事：HTML・CSS・JavaScriptの違い

division / div

divisionは「区分・分割された部分」の意味で、divの名前の元です。HTMLのdivは、複数の要素などを囲う汎用的なまとまりです。

関連記事：divとspanの違い

frontend / フロントエンド

利用者が画面で見たり操作したりする部分。WebではHTML・CSS・JavaScriptなどが関わります。

関連記事：HTML・CSS・JavaScriptの違い

HTML（エイチティーエムエル）

HyperText Markup Languageの略。文章に見出し・段落・リンクなどの目印を付け、ページの内容と構造を表します。

関連記事：HTML・CSS・JavaScriptの違い

Hypertext Reference / href

hrefの元の言葉。referenceは「参照」を意味し、リンクの移動先やCSSなどの参照先を表します。

関連記事：hrefとsrcの違い

identifier / 識別子（id）

「見分けるための名前」という意味で、idの元の言葉です。HTMLのidはページ内の特定の要素を指し、同じページ内で値を重複させません。

関連記事：classとidの違い

inline / インライン

文章の流れの中に続く表示。spanは標準ではインラインで、囲った範囲に沿って表示されます。

関連記事：divとspanの違い

JavaScript（ジャバスクリプト）

計算や、操作に応じた表示の更新などを行うプログラミング言語。Javaとは別の言語です。

関連記事：HTML・CSS・JavaScriptの違い

path / パス

英語で「道・経路」の意味。ファイルやフォルダの住所、そこまでたどる道順と考えると読みやすくなります。

関連記事：相対パスとは？

PWA（ピーダブリューエー）

Progressive Web Appの略。Webの技術を使い、対応する環境でアプリのような使い心地を提供するWebアプリです。

関連記事：1日でこのサイトを公開するまで

relative path / 相対パス

今いる場所を基準にした道順。HTML内の指定では通常そのHTMLの場所を基準にし、同じファイルでも現在地によって書き方が変わります。

関連記事：相対パスとは？

source / src

sourceは「元・出どころ」の意味。HTMLのsrcはその略で、画像やJavaScriptなどの読み込み元を表します。

関連記事：hrefとsrcの違い

span / スパン

英語で「範囲・広がり」、動詞では「一定の範囲を覆う」などの意味。HTMLでは文章などの一部分を汎用的に囲う要素です。

関連記事：divとspanの違い

navigation / nav

英語で「案内・移動」の意味。HTMLのnavはnavigationの略で、他のページやページ内の場所へ移動するための主要なリンク群をまとめる部分を表します。

関連記事：header・nav・main・section・articleの違い

semantic HTML（セマンティックHTML）

semanticは「意味に関する」という意味。意味を持つHTMLタグ（header・nav・main・section・articleなど）を使い、コードの構造を人間にもブラウザにも伝わりやすくする考え方です。

関連記事：header・nav・main・section・articleの違い

selector / セレクタ（CSSセレクタ）

英語で「選ぶもの」の意味。CSSでどのHTML要素にスタイルを適用するかを選ぶ部分です。

関連記事：CSSセレクタとは？

キャッシュ

一度読み込んだデータを保存し、再利用する仕組み。ブラウザに古いデータが残り、サイトを修正しても以前の表示が見える場合があります。

関連記事：1日でこのサイトを公開するまで

attribute / 属性

英語で「特徴・属性」の意味。HTMLタグに追加の情報を与えるもので、class・id・href・srcなどがこれに当たります。開始タグ内の「タグ名 属性名="値"」の形で書きます。

関連記事：属性とは？、HTMLタグとは？

nesting / 入れ子

タグの中に別のタグを入れる構造のこと。nestは英語で「巣」の意味から「組み合わさって収まる形」を表します。HTMLは入れ子によって箱の中に箱が入る構造を表現します。

関連記事：HTMLタグとは？

tag / タグ

英語で「札・ラベル・荷札」の意味。HTMLでは< >で囲まれた目印で、「これは見出し」「これは段落」のように要素の役割を示します。

関連記事：HTMLタグとは？

void element（空要素）

終了タグを持たないHTML要素のこと。<img>・<meta>・<br>などが該当します。「自己完結する指示」として機能するため、閉じタグが不要です。

関連記事：HTMLタグとは？

属性名（ぞくせいめい）

属性の名前の部分。class="card" なら class が属性名。どのような追加情報を与えるかを示します。

関連記事：属性とは？

属性値（ぞくせいち）

属性に設定する具体的な値。class="card" なら "card" が属性値。引用符で囲んで書きます。

関連記事：属性とは？

classセレクタ（クラスセレクタ）

.card のように . を先頭に付け、指定したclass名を持つ要素を対象にするCSSの書き方です。

関連記事：CSSセレクタとは？、classとidの違い

idセレクタ（アイディーセレクタ）

#start のように # を先頭に付け、指定したid名を持つ特定の要素を対象にするCSSの書き方です。

関連記事：CSSセレクタとは？、classとidの違い

要素セレクタ（ようそセレクタ）

p や div のようにタグ名を直接セレクタとして書き、その種類のタグすべてを対象にするCSSの書き方です。

関連記事：CSSセレクタとは？

API（エーピーアイ）

Application Programming Interfaceの略。プログラム同士が、決められた方法で機能やデータをやり取りする窓口です。

関連記事：APIとは？、4つのAIによるAPI説明の比較

function / 関数（かんすう）

名前を付けて呼び出せる処理のまとまり。functionには英語で「機能・働き」という意味があります。

関連記事：functionとは？

JSON（ジェイソン）

JavaScript Object Notationの略。名前と値などを決まった書式の文字で表すデータ形式で、APIのやり取りによく登場します。

関連記事：JSONとは？

オブジェクト

名前（キー）と値を組み合わせたデータのまとまり。人の名前・年齢など、関連する情報をまとめて読むときに出てきます。

関連記事：JSONとは？

キー / 値（あたい）

キーは項目名、値はその中身。JSONの「"name": "Masa"」なら、nameがキー、Masaが値です。

関連記事：JSONとは？

条件分岐（じょうけんぶんき）

条件に合うかどうかで、実行する処理が分かれること。ifやelseを見かけたら、その分かれ道を確認します。

関連記事：if文とは？

array / 配列（はいれつ）

複数の値を順番に並べて1つにまとめて扱う箱。角かっこ [ ] で囲み、カンマで区切って表します。

関連記事：配列とは？、JSONとは？

argument / 引数（ひきすう）

関数や機能へ渡す材料・情報。呼び出しの丸かっこの中を見て「この情報を渡している」と読みます。英語の argument は引数を意味します。

関連記事：. と () は何？、functionとは？

変数（へんすう）

値に名前を付けて扱うもの。その名前にどんな値が入るかを追うと、コードの流れが読みやすくなります。

関連記事：変数とは？

戻り値（もどりち）

関数から呼び出し元へ返される結果。returnの後ろを見ると、何を返しているか確認できます。

関連記事：returnとは？、functionとは？

関数呼び出し（かんすうよびだし）

関数の名前の後ろに () を付けて、その処理を実行すること。() は機能を動かすスイッチの役割を果たします。

関連記事：. と () は何？、functionとは？

ドット（.）

オブジェクトの中にある機能やデータを取り出す記号。「左のものの中にある右のもの」と読みます。

関連記事：. と () は何？

return（リターン）

functionの中で作った結果を外に渡す命令。英語で「返す・戻す」の意味。returnが実行されるとその関数は終了します。

関連記事：returnとは？

index / インデックス（添字）

配列の中の要素の位置を表す番号。JavaScriptでは0から始まり、先頭の要素は [0] と指定します。

関連記事：配列とは？

要素（ようそ / element）

配列の中に入っている1つひとつのデータのこと。英語で element（エレメント）といいます。

関連記事：配列とは？

二次元配列（にじげんはいれつ）

配列の中にさらに配列が入っている入れ子構造。スプレッドシートの行と列のように、表形式のデータを扱うときによく登場します。

関連記事：配列とは？

length（要素数・長さ）

配列にいくつの要素が入っているかを表すプロパティ。array.length で個数を取得できます。

関連記事：配列とは？

GAS（ガス）

Google Apps Scriptの略称。JavaScriptを使い、GmailやスプレッドシートなどのGoogleサービスを操作する仕組みです。

関連記事：Google Apps Script（GAS）とは？

GASサービス / 組み込みサービス

GASにあらかじめ用意されている、Googleサービスごとの機能の入口。SpreadsheetApp（スプレッドシート）・GmailApp（Gmail）・CalendarApp（カレンダー）・DriveApp（ドライブ）などがあります。コードの左端に現れ、どのサービスを操作しているかの目印になります。

関連記事：SpreadsheetApp・GmailApp・CalendarAppとは？、Google Apps Script（GAS）とは？

trigger / トリガー

処理を自動で始めるきっかけ。英語では「引き金」を意味し、指定時刻やフォーム送信などをきっかけにします。

関連記事：トリガーとは？

実行ログ（じっこうログ）

処理の途中や結果を確認するための記録。Logger.log()で出力した内容などを確認できます。

関連記事：変数とは？

amend（アメンド）

英語で「修正する」の意味。Gitでは直前のcommitを作り直す操作で、送信済みのcommitに使うと手元と接続先の履歴が分かれることがあります。

関連記事：1日でこのサイトを公開するまで

commit（コミット）

選んだ変更を、ローカルの履歴に記録すること。ファイルの保存やGitHubへの送信とは別の操作です。

関連記事：GitとGitHubとは？

diff（ディフ）

変更前後の違い（差分）。追加・削除された行を見て、AIがどこを直したのか確認できます。

関連記事：GitとGitHubとは？

Git（ギット）

ファイルの変更履歴を記録する仕組み。過去の状態と比べたり、変更を追ったりできます。

関連記事：GitとGitHubとは？

GitHub（ギットハブ）

Gitで管理するコードや履歴をオンラインで保存・共有するサービス。Hub（集まる場所）と結び付けると覚えやすくなります。

関連記事：GitとGitHubとは？

GitHub Pages（ギットハブ・ページズ）

GitHubのリポジトリにあるHTMLやCSSなどを、Webサイトとして公開するサービスです。

関連記事：1日でこのサイトを公開するまで

pull（プル）

接続先の履歴を取得し、手元の作業へ取り込むこと。英語の「引き寄せる」と方向を結び付けて覚えられます。

関連記事：GitとGitHubとは？

push（プッシュ）

手元でcommitした履歴を接続先へ送ること。英語の「押し出す」と方向を結び付けて覚えられます。

関連記事：GitとGitHubとは？

repository / リポジトリ

プロジェクトのファイルと変更履歴を管理する場所。手元のPCにも、GitHub上にも置けます。

関連記事：GitとGitHubとは？

revert（リバート）

過去のcommitの変更を打ち消す操作。通常は元の履歴を残し、取り消すための新しいcommitを作ります。

関連記事：GitとGitHubとは？

ステージング

次のcommitに含める変更を選ぶこと。履歴へ記録する前の準備です。

関連記事：GitとGitHubとは？

リモート / ローカル

リモートはGitHubなどの接続先、ローカルは手元の作業場所。pushやpullの説明では、どちら側かを確認します。

関連記事：GitとGitHubとは？
